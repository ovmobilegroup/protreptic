# International Figures Quality Checklist

## Overview
This document contains quality standards and checklists for international historical figures in the Protreptic system.

## Quality Standards

### 1. Bilingual Completeness
- [ ] All figures have both Chinese (zh) and English (en) versions
- [ ] Chinese and English names are accurate translations
- [ ] Descriptions, reasoning, and case studies are available in both languages
- [ ] Mode names are translated appropriately
- [ ] Historical periods are standardized across languages

### 2. Historical Accuracy
- [ ] All figures have verifiable historical sources
- [ ] Wikipedia QIDs are provided for cross-referencing
- [ ] Historical periods are accurate and well-defined
- [ ] Nationality and civilization sphere are correctly identified
- [ ] Primary language of historical documents is specified

### 3. Mode Coverage Requirements
- [ ] Each figure covers at least 1 zero-coverage thinking mode
- [ ] Mode assignments are accurate and relevant to the figure's historical contribution
- [ ] Cross-disciplinary thinking modes are encouraged
- [ ] Mode diversity across nationalities is maintained
- [ ] Mode names are culturally appropriate

### 4. Code Prefix System
- [ ] International prefixes follow consistent format: {PREFIX}-{TOPIC}-{NNN}
- [ ] Korean figures use KR- prefix
- [ ] Brazilian figures use BR- prefix
- [ ] Other international prefixes are properly registered
- [ ] Prefixes are unique and non-overlapping

### 5. Quality Metrics
- [ ] Data structure follows international_schema_v2.md requirements
- [ ] All mandatory fields are present (code, name_zh, name_en, core_mode, era, country, etc.)
- [ ] Optional fields are appropriately populated when available
- [ ] Historical domains and thinking domains are correctly categorized
- [ ] Gender and ethnicity are accurately represented

### 6. Cross-National De-duplication
- [ ] Figures with similar historical periods across countries are flagged for review
- [ ] Cross-cultural influence cases are clearly attributed
- [ ] Migration of historical figures between countries is documented
- [ ] Similar historical contributions are distinguished by context and era

### 7. International Schema Compliance
- [ ] New fields (nationality, civilization_sphere, time_period_standardized, wiki_id, primary_language, intellectual_tradition) are implemented
- [ ] Existing fields are properly documented
- [ ] Schema changes are backward compatible
- [ ] Quality assurance processes are established

## Implementation Guidelines

### For New Figures
1. Research historical accuracy thoroughly using multiple sources
2. Verify Wikipedia QID availability
3. Determine appropriate thinking modes based on historical contribution
4. Ensure bilingual completeness before submission
5. Follow international prefix registry for code assignment

### For Quality Review
1. Cross-reference historical information with authoritative sources
2. Verify mode assignments with historical contribution analysis
3. Check for duplicates with existing international figures
4. Ensure cultural appropriateness of mode names and descriptions
5. Validate completeness of required fields

### For Maintenance
1. Regularly update historical information as new research emerges
2. Review and update mode assignments based on evolving understanding
3. Maintain cross-national consistency in data structure
4. Update quality checklist based on review findings

## Quality Assurance Process

### Step 1: Initial Validation
- Verify all required fields are present
- Check bilingual completeness
- Validate historical accuracy
- Ensure mode coverage requirements are met

### Step 2: Cross-Validation
- Check for duplicates with existing figures
- Verify cross-national consistency
- Validate schema compliance
- Ensure quality standards compliance

### Step 3: Final Review
- Comprehensive quality assessment
- Stakeholder feedback incorporation
- Documentation update
- Process improvement identification

## Quality Metrics and KPIs

### Quantitative Metrics
- **Completeness Score**: % of required fields populated
- **Bilingual Compliance**: % of figures with complete bilingual versions
- **Historical Accuracy**: % of figures verified with authoritative sources
- **Mode Coverage**: Average number of thinking modes per figure
- **Schema Compliance**: % of figures following international_schema_v2.md

### Qualitative Metrics
- **Cultural Appropriateness**: Cultural sensitivity and appropriateness of content
- **Think Mode Relevance**: Relevance and appropriateness of thinking mode assignments
- **Historical Significance**: Quality and significance of historical content
- **Cross-Cultural Value**: Value of cross-cultural representation and understanding
