## 🥇 第一板斧：入职即"结义" — 文化对齐仪式设计

### 1.1 桃园结义式入职仪式 (Day 1)

```markdown
## 🌸 桃园结义 · 入职仪式流程 (3小时)

### 09:00-09:30 签到·佩戴令牌
- 领取：文化手册(含《隆中对》战略版)、定制徽章、结义契约书
- 佩戴："仁义礼智信"五色令牌(对应五大价值观)
- 扫码加入："桃园结义群"(全员文化社群)

### 09:30-10:30 创始人故事会·共饮文化酒
- 创始人讲述：为什么创业、最绝望时刻、最感动瞬间、未来愿景
- 新员工轮流分享：我为什么来、我想成为什么样的人、我怕什么
- 共饮："文化酒"(无酒精仪式饮品) —— 象征利益同享、风险共担

### 10:30-11:00 结义宣誓·签署契约
- 全员起立，面向使命墙宣誓：
  "我不同年同月同日生，但愿同年同月同日死。
  同心协力，共创大业；有福同享，有难同当。
  仁以爱人，义以正己，智以成事。"
- 签署：《结义契约书》(含文化契约、保密协议、期权授予)

### 11:00-11:30 导师结对·赠送装备
- 宣告："XXX为你的结义大哥/大姐"(导师制)
- 赠送：定制笔记本(首页印使命)、文化T恤、专属工位牌
- 导师带领：参观"桃园圣地"(荣誉墙/失败墙/创始人工位)

### 11:30-12:00 首餐同桌·融入团队
- 团队欢迎午餐(公司承担)
- 破冰游戏："三国杀·团队版" / "我的用户画像"
```

## 🥈 第二板斧：复盘即"隆中对" — 战略对齐仪式设计

### 2.1 隆中对式季度复盘会 (Quarterly Strategic Review)

```markdown
## 📊 隆中对式季度复盘会 (半天/季度)

### 会前准备 (T-7天)
□ 各BU提交：《隆中对执行版》更新版(战略/战术/资源/风险)
□ 数据组准备：北极星指标/关键漏斗/单位经济模型/现金流
□ 竞情组准备：竞对动向/市场变化/技术突破/政策法规
□ 文化组准备：价值观践行案例/违规案例/荣誉榜单

### 议程流程 (4小时)

#### 09:00-09:30 战略复盘——"隆中对"对标检查
- 创始人宣读：《隆中对》原文核心三段(荆益据守/两路北伐/中原决战)
- 各BU汇报：本季度在"据守/北伐/决战"三阶段的进展/偏差/修正
- 关键提问：
  "我们的'荆州'(核心根据地)稳不稳？"
  "我们的'益州'(新增长极)建得如何？"
  "我们的'北伐'(核心战役)胜算几成？"

#### 09:30-10:30 战术复盘——胜仗/败仗深度剖析
- 胜仗复盘(3个)：
  背景→目标→关键动作→关键决策→可复用模式→推广计划
- 败仗复盘(3个)：
  背景→目标→偏差点→根因(战略/战术/执行/运气)→反模式沉淀→防范措施
- 关键原则：只复盘不问责、只找模式不找人、只沉淀不归档

#### 10:30-11:30 资源重分配——"屯田制"预算调整
- 展示：现金流/人力/算力/渠道/品牌 五大资源池现状
- 决策：砍掉什么(止损) / 加码什么(加注) / 实验什么(探索)
- 产出：《下季度资源分配令》(CEO签署、全员公示)

#### 11:30-12:00 文化对齐——"桃园结义"活度检查
- 价值观践行榜单：表彰"仁义智"标兵(实名、实事、实效)
- 违规曝光台：通报违背价值观行为(实名、实事、整改)
- 荣誉授勋：季度MVP/最佳新人/最佳协作/最佳复盘
- 新老传承：老员工讲"我的第一个隆中对"故事
```

## 🥉 第三板斧：离职即"白帝托孤" — 体面离场与传承机制

### 3.1 白帝城托孤式离职流程

```markdown
## 🏛️ 白帝城托孤 · 离职仪式流程 (离职前30天启动)

### Phase 1: 托孤准备期 (D-30 ~ D-15)
□ 书面离职申请 + 面谈沟通真实原因
□ 确定：继任者 / 交接清单 / 核心资产清单 / 风险预案
□ 签署：《托孤交接书》(含保密/竞业/知识产权/客户移交)
□ 发布：内部通告(正面正向、尊重体面、欢迎回归)

### Phase 2: 交接执行期 (D-15 ~ D-3)
□ 文档交接：代码/设计/文档/流程/账号/配置 全量归档
□ 知识交接：1对1讲解×3次 + 录制视频教程 + 编入知识库
□ 关系交接：核心客户/合作伙伴/供应商 逐个介绍介绍
□ 资产交接：设备/权限/钥匙/卡/证/合同/发票/印章
□ 风险交接：进行中项目/潜在坑/依赖方/应急联系人

### Phase 3: 托孤仪式日 (D-1 / 离职日)
#### 上午：白帝城托孤仪式 (30分钟)
- 创始人/部门负责人/导师/继任者/核心同事 共同见证
- 离职者宣读：《托孤遗言》(个人版)
  "吾本织席贩履之人，蒙组织不弃，待遇如鱼水。
  今因__________，不得不别。
  吾之未竟事业，托付__________；
  吾之核心客户，托付__________；
  吾之核心代码/配方/配方，托付__________；
  吾之未竟梦想，托付全体兄弟姐妹。
  望诸君：仁以爱人，义以正己，智以成事。
  兴复汉室，还于旧都；兴复使命，还于初心。"
- 继任者宣读：《受托誓言》并签署《受托书》
- 创始人/负责人：颁发"托孤令牌"、赠送《白帝城图》、合影留念

#### 中午：托孤宴 · 体面告别 (1小时)
- 团队聚餐(公司承担)，不谈工作只谈情谊
- 同事轮流送祝福："愿君前程似锦、再创大业"
- 赠送：《白帝城托孤纪念册》(含团队寄语/照片/成就记录)

#### 下午：行政闭环 · 校友入库 (30分钟)
- HR办理：离职证明/社保转移/公积金/个税/薪资结算
- IT办理：权限回收/邮件转发/账号冻结/数据归档
- 校友办：录入校友库/发放校友卡/加入校友群/赠送校友礼包
- 签署：《校友终身协议》(保密/推荐/投资/回归优先权)

### Phase 4: 托孤后续 (离职后)
□ D+7天：继任者首次复盘会，离职者可选列席指导
□ D+30天：校友回访，了解新动向，提供支持
□ D+90天：校友活动邀请，维持情感连接
□ D+365天：周年纪念日致信，邀请校友日回归分享
```

## 💡 一句话总结

> **刘备文化三板斧：**
> **入职如"桃园结义"——用仪式锚定信仰，用契约锁定承诺，用导师传递温度；**
> **复盘如"隆中对"——用战略对齐统一思想，用复盘沉淀提炼模式，用资源调度落地执行；**
> **离职如"白帝托孤"——用体面告别守护尊严，用交接传承守护资产，用校友体系守护生态。**
> **—— 这是一套"让文化可视化、可操作化、可度量化、可传承化"的文化工程化落地系统。**
