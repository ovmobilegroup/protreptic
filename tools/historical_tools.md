```
4. 保留核心种子团队(≤5人)和核心技术资产，进入下一轮蛰伏
```

## ☯️ 工具 3：王阳明知行合一检查表（模式37）

**适用场景**：知行分离严重/执行力差/学而不练/战略落地难/个人成长停滞

### 一、认知审计清单（每月必做）

```
列出"我认为正确但未付诸行动"的认知清单
格式：| 认知内容 | 确信度(1-10) | 阻碍行动的原因 | 最小可行性行动(MVA) | 截止日期 | 问责伙伴 |
|--------|-------------|---------------|-------------------|----------|---------|
| 例：用户调研是产品成功关键 | 9 | 没时间/不会设计问卷 | 本周访谈3个种子用户 | 周五 | 产品伙伴 |
| 例：复盘能提升团队30%效率 | 8 | 形式主义/不敢说真话 | 本周五晚主持1次真复盘 | 周五 | 技术负责人 |
| 例：英语是核心竞争力 | 7 | 怕开口/单词背不下 | 每天1个TED精听+影子跟读 | 每晚 | 英语搭档 |
```

### 二、MVA（最小可行性行动）设计原则

| 原则 | 反例 | 正例 |
|------|------|------|
| **成本<1小时/100元** | "先买幂英语课再学" | "今天背10个单词+1句跟读" |
| **可在24小时内启动** | "下周一准备开始" | "现在打开录音笔读1段" |
| **结果可观测/可验证** | "多读书提升认知" | "读完1章写300字心得发朋友圈" |
| **失败成本可控** | "裸辞创业验证想法" | "周末接1个付费咨询单测试" |
| **可迭代/可复利** | "一次性突击复盘" | "建立周复盘模板，每周五固定30分钟" |

### 三、每日/每周/每月闭环模板

#### 每日知行合一记录卡（睡前5分钟）

```
日期：_______
1. 今天"知而不行"的事：_______________ (诚实记录，不自责)
2. 原因诊断：恐惧/懒惰/完美主义/没工具/没榜样/优先级错
3. 明天的MVA：_______________ (必须符合上述5原则)
4. 良知拷问：这事做得对不对？良心安不安？_______________
```

#### 每周知行复盘会（周五晚30分钟，可独自/搭档/团队）

```
议程：
1. 回顾本周MVA完成率：____/____ (完成/计划)
2. 成功案例：哪个MVA效果超预期？为什么？提炼可复用模式
3. 失败案例：哪个MVA没做/做砸？根因是认知偏差/工具缺失/环境阻力/优先级错？
4. 认知修正：基于本周实战，哪些"自以为正确"的认知需要更新？
5. 下周MVA清单：列出3-5个，每个指定责任人/截止时间/验收标准
6. 良知集体校准：团队层面"这事对不对？"的共识确认
```

#### 每月知行进化报告（月度深度复盘）

```
核心指标：
- MVA完成率趋势图(连续6个月)
- 认知更新数：本月修正/新增了多少个核心认知
- 知行差距收敛度：(已验证通过认知数 - 行动落地认知数) / 验证通过认知数
- 复利产出：沉淀了多少SOP/教程/案例库/工具模板

下月重点突破：_______________
需要的资源/支持：_______________
```
