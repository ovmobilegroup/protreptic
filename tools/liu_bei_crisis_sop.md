## 三、危机应对标准作业程序 (SOP)

### SOP-01：核心将领阵亡/失联 (如关羽/张飞/赵云)

```
触发条件：核心一级将领阵亡、被俘、失联超72小时
响应时限：2小时内启动，24小时内完成部署

步骤：
1. 确认信息：多渠道交叉验证(军报/降卒/商旅/敌方公告)
2. 封锁消息：军中仅报"将军负伤/巡视前线"，防军心动摇
3. 启动继任：按"人才冗余矩阵"调度二号人选接管兵权
4. 安抚部属：将军亲信/亲兵编入直属/分编他部，防离心
5. 对外宣示：以"将军病重/巡边"对外，待时机再发丧
6. 复盘归因：战术失误/战略失策/情报失准/内部背叛
7. 祭祀追谥：按礼制追谥、厚葬、抚恤三代、子嗣袭爵

预案文档：templates/crisis_general_fallen.md
演练频次：每年一次桌面推演
```

### SOP-02：根据地失守/被围 (如荆州/汉中/成都)

```
触发条件：核心根据地被攻陷/围困超30天/粮草<15天
响应时限：1小时内启动，72小时内完成撤退部署

步骤：
1. 研判形势：守/撤/降三选一决策树(见决策树模板)
2. 核心资产转移：人才/档案/金银/种子/图籍/工匠优先
3. 分批撤退：核心层→军事层→行政层→百姓自愿
4. 焦土/毁灭：粮仓/船只/兵器/桥梁/道路必要时毁
5. 指挥前置：最高决策者前移至次级根据地(如白帝城)
6. 求援/联盟：激活外交冗余，请盟友牵制/派兵/给粮
7. 固守待变：利用地形固守，等待敌方补给线过长/内部矛盾

预案文档：templates/crisis_base_lost.md
演练频次：每两年一次实地演练
```

### SOP-03：继承危机/权力真空 (如君主驾崩/幼主即位)

```
触发条件：最高决策者驾崩/失能/被俘，无明确继承人/继承人幼弱
响应时限：即时启动(遗诏生效)，7天内完成权力交接

步骤：
1. 宣读遗诏/托孤诏书：按预设文本宣读，确立合法性
2. 核心团队集体亮相：丞相/大将军/尚书令/侍中联合署名
3. 宗室/重臣会议：按"托孤制"确定辅政/参赞/监察分工
3. 军权收归：禁卫/京畿/重镇兵权按预设方案分配/轮换
4. 安抚人心：赦令/蠲税/恤孤/抚伤/褒/封赏/起复
5. 对外通报：致盟友/敌国/藩属书信，展示稳定/延续
6. 监察介入：董允/陈祗等监察官监督权力运行防专擅

预案文档：templates/crisis_succession.md
演练频次：每年一次桌面推演，每5年一次实地演练
```

### SOP-04：财政/粮食崩溃 (如币制崩溃/连年饥荒/军饷发不出)

```
触发条件：军饷拖欠>3月/粮价超平时5倍/币值贬值>90%/仓库<6月军需
响应时限：24小时内启动方案，1周内见效

步骤：
1. 紧急止血：冻结非战略支出、裁撤冗员、停建非急工程
2. 变现资产：皇室/宗室/豪强/寺观金银/珠宝/良田/库存变现
3. 货币改革：收旧铸新/定值发行/限额兑换/打击私铸/建信用
4. 屯田军粮：全民屯田/军队自给/盐铁专卖收益拨补/对外贸易换粮
5. 分级供给：前线/核心/次要/后方 四级差别供给
6. 求援借粮：盟友/藩属/商贾/甚至敌对方(人道主义/交换条件)
7. 舆论引导：公开账本/严惩贪腐/表彰节俭/树立榜样

预案文档：templates/crisis_fiscal.md
演练频次：每年一次桌面推演
```

## 七、刘备式危机管理黄金法则

```
□ 永远准备"最坏情况"的Plan B/C/D，而非赌"最好情况"
□ 永远保留"最后根据地"(白帝城)和"最后撤退路"(阴平道)
□ 永远建立"人才冗余矩阵"，关键岗位无单点依赖
□ 永远在"顺境"时建立"逆境"机制(托孤制/遗诏/冗余备份)
□ 永远用"文化/荣誉/情感"绑定核心团队，而非仅靠利益
□ 永远在危机时"最高决策者前移一线"(刘备白帝城/长坂坡/定军山)
□ 永远"体面退出"而非"死守体面"(白帝城托孤 vs 关羽麦城死守)
□ 永远保护"种子"(后主/核心团队/文化基因/档案图籍)优于"果实"(领土/城池/金银)
□ 永远事后"复盘归因不追责个人、沉淀反模式、更新预案"
□ 永远将"危机应对能力"纳入核心人才晋升/考核/选拔标准
```

> **刘备危机管理精髓：**
> **不是没有危机，而是每次危机都有预案；不是不失败，而是失败在可控范围内；不是不死人，而是核心种子永远活下来。**
> **—— 这就是为什么蜀汉能在三国最弱、环境最恶劣条件下存续43年，并留下千古传颂的文化基因。**
