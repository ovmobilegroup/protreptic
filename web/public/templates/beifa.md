### 第一步：战略定力 —— **「汉贼不两立」的使命锚定** (Mission Anchoring)

> **核心**：“汉贼不两立，王业不偏安” —— 不因一时得失动摇，不因资源受限放弃

| 维度 | 诸葛亮设定 | 现代映射 | 自检清单 |
|------|------------|----------|----------|
| **使命** | 兴复汉室 / 还于旧都 | 公司愿景 / 产品使命 / 社会价值 | [ ] 使命是否清晰 [ ] 团队共识 [ ] 耐得住寂寞 |
| **底线** | 不降曹 / 不偏安 | 不妥协核心价值 / 不放弃核心赛道 | [ ] 红线明确 [ ] 诱惑面前不妥协 |
| **节奏** | 六出祁山 / 持久战 | 长期主义 / 复利思维 / 阶段性交付 | [ ] 接受长周期 [ ] 拒绝短期功利 |
| **资源观** | 以弱胜强 / 精打细算 | 资源受限 / 精益创新 / 杠杆思维 | [ ] 接受资源少 [ ] 擅长杠杆 [ ] 不抱怨资源少 |

## 🎯 核心心法

> **「鞠躬尽瘁，死而后已」**
> 
> 北伐的本质是 **「资源受限下的长期主义执行」**：
> 1. **使命锚定** (汉贼不两立) → 不因资源少/困难大而动摇
> 2. **阶段门控** (六出祁山) → 每次出师有目标、有门控、有复盘、有迭代
> 3. **极限创新** (木牛流马) → 在资源极限处发明新工具/新制度/新方法
> 4. **战略传承** (出师表/教子书/遗计) → 战略不随人终，制度/文化/梯队永续
> 
> **现代管理翻译**：
> - **长期主义 ≠ 盲目坚持，而是「阶段门控 + 复盘迭代 + 极限创新」的组合**
> - **资源少不是借口，是倒逼创新的催化剂 —— 木牛流马就是资源极限下的发明**
> - **最好的传承不是「留下钱」，而是「留下制度、文化、梯队、方法论」**
