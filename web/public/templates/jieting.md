## 🎯 核心心法

> **「授权不是放权，授权是『授权+监控+兜底』的完整链路」**
> 
> 街亭之战的本质是 **「授权链路断裂」**：
> 1. **选人模型失效** (马谡纸上谈兵 / 能力画像偏差) → 必须建立「实战验证 + 多维评价 + 试错容错」的选人模型
> 2. **授权边界模糊** (节度不清 / 无强制约束) → 必须建立「授权矩阵 + 边界清单 + 强制约束 + 熔断机制」的授权标准
> 3. **监控无牙齿** (王平谏不听 / 无强制干预权) → 必须建立「监控有介入权 + 熔断机制 + 升级路径 + 兜底预案」的监控标准
> 4. **兜底预案缺失** (王平别营自保 / 事后收残) → 必须建立「熔断降级 + 兜底预案 + 残局收拾 + 损失控制」的兜底标准
> 5. **问责不闭环** (斩马谡 / 自贬三等 / 机制修补不明确) → 必须建立「个人问责 + 监控问责 + 授权者担责 + 机制修补验证」的闭环问责
> 
> **现代管理翻译**：
> - **授权 = 授权矩阵 + 监控仪表板 + 熔断机制 + 兜底预案 + 闭环问责**
> - **不授权给「聪明人」，要授权给「经过验证、边界清晰、可监控、有兜底」的人**
> - **最好的授权不是「信任」，而是「不需要信任也能运行的制度」**
