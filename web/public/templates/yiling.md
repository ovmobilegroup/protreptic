## 🎯 夷陵三步法：情绪化决策崩溃标准化复盘框架

### 第一步：情绪溯源 —— **「大怒 / 拒谏 / 亲征」的情绪决策链** (Emotional Decision Chain)

> **核心**：“先主大怒……遣使招吴班等……群臣谏不听……自率诸军伐吴” —— 情绪如何一步步接管决策系统

| 情绪阶段 | 触发事件 | 情绪反应 | 认知扭曲 | 决策动作 | 专业建议 | 采纳情况 |
|----------|----------|----------|----------|----------|----------|----------|
| **愤怒爆发** | 关羽败走麦城 / 荆州失守 / 关羽遇害 | 极度愤怒 / 义愤填膺 / 复仇心切 | **情绪合理化**：复仇=正义 / 忽视国力对比 | 拒绝孙权求和 / 处死孙权使者 / 备战伐吴 | 诸葛亮/赵云/蒋琬/费祎/秦宓等群臣联名上谏 | ❌ 全盘拒绝 / “吾志已决，不可沮也” |
| **拒谏固执** | 群臣百官联名上谏 / 赵云“国贼是曹操非孙权” | 恼羞成怒 / 面子挂不住 / 权威受挑战 | **确认偏误**：只听支持/拒绝反对 / 权威偏见 | 斥退谏臣 / 罢免反对官员 / 整军备战 | 赵云/蒋琬/费祎/秦宓等再三苦谏 / 赵云直言“陛下以私仇报国仇” | ❌ 完全无视 / “吾志已决，不可复谏” |
| **亲征冒进** | 大军东下 / 舍甲胄 / 连营七百里 / 拒谏不设伏兵 | 豪情万丈 / 必胜信念 / 英雄情结 | **过度自信/幸存者偏差**：过往胜利归因于自己 / 忽视运气/对手/环境 | 亲自统帅 / 连营七百里 / 拒陆逊诱饵 / 深入吴境 | 吴班/陈式建议设伏兵 / 马良建议留守 / 诸葛亮遗书诫勿轻进 | ❌ 全盘无视 / “吾已决策，岂可中变” |

**🎯 核心算子**：**情绪决策接管度** = (情绪强度 × 决策权重 × 拒谏程度 × 冲动行动) / 专业建议权重
> **现代公式**：`情绪决策接管度 = (情绪强度 × 决策独断度 × 拒谏程度 × 冲动行动) / (专业建议权重 × 数据支持度 × 风险评估深度)`，目标 < 0.3

## 🎯 核心心法

> **「以私仇报国仇，以匹夫之勇决国家之策，必败无疑」—— 赵云**
> 
> 夷陵之战的本质是 **「情绪劫持决策系统」**：
> 1. **情绪劫持** (愤怒/复仇/面子) → 接管决策系统 → 专业建议被屏蔽
> 2. **目标置换** (战略目标 → 情绪目标) → 复仇 > 国计 / 面子 > 里子 / 私仇 > 公仇
> 3. **认知封闭** (拒谏 / 确认偏误 / 过度自信) → 信息过滤 / 只听支持 / 拒绝反馈
> 4. **冒进冒险** (连营七百里 / 舍险就平 / 拒谏不设伏) → 战略失焦 / 战术自杀
> 5. **系统崩溃** (火攻 / 溃败 / 托孤) → 组织濒死 / 继任危机 / 制度重构
> 
> **现代管理翻译**：
> - **CEO最大的风险不是能力不足，而是情绪劫持决策权**
> - **最危险的不是犯错，而是犯错后拒绝修正、拒绝听取反对意见**
> - **最好的治理不是「圣人治理」，而是「情绪劫持时也能自动纠偏的制度」**
> - **治理 = 情绪隔离层 + 专业决策层 + 制衡监督层 + 止损熔断层 + 传承兜底层**
