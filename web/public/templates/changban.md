# 🏃 长坂坡复盘模板

> **原典**：《三国志·赵云传/先主传》——“曹操大军至，先主弃妻子，走……云护卫主母，身被重创……主曰：‘子龙，救我子！’云曰：‘请以死奉命’”
> **核心**：**极限生存 / 单点突围 / 核心资产护送 / 以弱胜强 / 信守承诺**
> **现代译法**：**极端劣势下如何完成「核心资产护送 + 单点突围 + 信守承诺」的标准化生存突围范式**

---

## 🎯 长坂三步法：极限生存突围标准化框架

### 第一步：核心资产识别与护送优先级 —— **「子龙，救我子！」的资产分级护送** (Asset Triage & Protection)

> **核心**：“主曰：‘子龙，救我子！’云曰：‘请以死奉命’” —— 在极限资源下，**只护送核心中的核心**

| **A级：延续核心** | 关羽/张飞/赵云等核心将领 / 核心文臣 | **核心技术骨干/核心销售/核心运营/核心研发/关键渠道/核心供应商关系** | **P1：极力保** | 核心高管分散护送 / 关键文档加密随身 / 核心代码离线备份 / 关键账号权限转移 | 可接受部分损失 / 但必须保核心能力复原力 |

**🎯 核心算子**：**护送通过率** = (S级存活数/S级总数) × 100% → 必须 = 100%

## 🎯 核心心法

> **「子龙一身都是胆」—— 曹操**
> 
> 长坂坡的本质是 **「极限约束下的单点突围」**：
> 1. **资产分级** (只护核心中的核心) → P0 必须 100% 活，P3 果断弃
> 2. **单点穿透** (单骑杀入杀出) → 资源极度集中 / 指挥极度扁平 / 决策极度下放
> 3. **极限机动** (轻装疾行 / 不恋战 / 不贪功) → 团队极简 / 流程极简 / 审批极简 / 指标极简
> 4. **心理震慑** (曹操生致之 / 子龙一身都是胆) → 声誉杠杆 / 不确定性 / 对手心理防线击穿
> 5. **承诺锚定** (请以死奉命 / 誓死护主 / 身被重创不退) → 身份认同 / 使命超越生死 / 信念大于生死
> 6. **生存后重建** (护送归还 / 封翊军将军 / 终成名将) → 核心资产零损失归位 / 组织重建 / 战略回归 / 文化传承
> 
> **现代管理翻译**：
> - **活下去的核心不是「多做」，而是「只做 P0」—— 剩下的都是噪音**
> - **突围的核心不是「全线出击」，而是「单点穿透」—— 集中一切资源撕开一个口子**
> - **极限生存的核心不是「能力」，而是「承诺」—— 「请以死奉命」比任何战术都管用**
> - **最好的生存不是「苟活」，而是「带着核心资产、核心团队、核心承诺，杀出一条生路，然后重建帝国」**
