## 一、映射原则与设计逻辑

### 映射三原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **功能匹配** | 思维模式的核心功能与写作技法的表现功能必须一致 | 矛盾分析（揭示对立）→ 对比论证（正反对比） |
| **受众适配** | 思维模式的目标受众决定写作技法的通俗程度 | 群众路线（面向大众）→ 民间俗语化（通俗易懂） |
| **节奏共振** | 思维模式的推进节奏与写作技法的结构节奏相吻合 | 持久战（三阶段）→ 编号列举（逐条推进） |

### 设计逻辑

```
思维模式（分析问题） → 选择写作技法（表达分析） → 输出结构化文章
```

- **每种思维模式推荐1-2种核心写作技法**
- **映射关系有明确的逻辑支撑**（功能匹配/受众适配/节奏共振）
- **多技法组合**：复杂思维模式可匹配多种写作技法

## 三、"思维→写作"完整流程

### 3.1 四步流程总览

```
┌─────────────────────────────────────────────────────────┐
│                    思维→写作 完整流程                      │
│                                                         │
│  第一步                第二步              第三步          │
│  分析问题              选技法               输出文章        │
│  ┌─────────┐         ┌─────────┐        ┌─────────┐      │
│  │用思维    │         │根据      │        │用写作    │      │
│  │模式     │────────▶│映射表     │────────▶│技法     │      │
│  │定位核心  │         │选1-2种    │        │结构化    │      │
│  │矛盾/问题 │         │核心技法   │        │表达      │      │
│  └─────────┘         └─────────┘        └─────────┘      │
│                                                         │
│  第四步                                                  │
│  验证与迭代                                               │
│  ┌─────────┐                                             │
│  │读者反馈  │◀─────────────────────────────────────┐     │
│  │是否清晰  │                                        │     │
│  │是否有说服力│                                       │     │
│  └─────────┘                                        │     │
│              └───────────────────────────────────────┘     │
│                          ↓ 不满足则返回第三步调整            │
└─────────────────────────────────────────────────────────┘
```

### 3.2 第一步：用思维模式分析问题

**操作清单：**

1. **识别问题类型**
   - 方向性问题 → 用矛盾分析法找核心矛盾
   - 突破性问题 → 用灵活策略法打开思路
   - 人相关问题 → 用群众路线法获取真实信息
   - 长期性问题 → 用持久战思维规划阶段

2. **选择核心思维模式**

   ```
   问题特征                    →  推荐思维模式
   ──────────────────────────────────────────
   多重矛盾交织                →  矛盾分析法 (#1)
   需要从一线获取信息          →  群众路线法 (#2)
   对手强大，需要长期策略      →  持久战思维 (#3) + 农村包围城市 (#4)
   需要实事求是的决策          →  实事求是法 (#5)
   需要团结多方力量            →  统一战线法 (#6)
   需要做前瞻性规划            →  战略预判法 (#7)
   需要渐进式推进              →  渐进改革法 (#8)
   需要独立自主                →  独立自主法 (#9)
   需要持续改进                →  批评与自我批评法 (#10)
   需要灵活应变                →  灵活策略法 (#11)
   需要全局视角                →  系统思维法 (#12)
   ```

3. **输出分析结果**
   - 主要矛盾/核心问题
   - 关键因素/利益相关方
   - 最优策略/行动方向

### 3.3 第二步：根据分析结果选择合适的写作技法

**操作清单：**

1. **确定文章类型**

   ```
   文章类型              →  推荐写作技法组合
   ──────────────────────────────────────────
   政策分析报告          →  对比论证 + 编号列举
   动员演讲              →  民间俗语化 + 排比收尾
   理论阐释              →  设问开场 + 历史典故
   工作总结              →  先扬后抑 + 编号列举
   批评文章              →  讽刺笔法 + 对比论证
   对外宣传              →  问答体 + 寓言故事化
   政策解读              →  民间俗语化 + 设问开场
   战略谋划              →  设问开场 + 编号列举
   ```

2. **根据思维模式匹配技法**
   - 用映射表查找思维模式对应的写作技法（见第二部分）
   - 选择1-2种核心技法，最多不超过3种
   - 考虑受众：大众→俗语化/寓言化；专业→编号列举/对比论证

3. **确定文章结构**

   ```
   技法组合                  →  文章结构
   ──────────────────────────────────────────
   设问开场 + 对比论证       →  提问→正反对比→结论
   编号列举 + 排比收尾       →  逐条分析→排比号召
   寓言故事化 + 民间俗语化   →  讲故事→通俗总结
   先扬后抑 + 编号列举       →  肯定成绩→指出问题→逐条整改
   ```

### 3.4 第三步：用写作技法输出结构化文章

**操作清单：**

1. **开场设计**（30秒吸引读者）
   - 设问开场："XX对吗？不对。为什么呢？因为……"
   - 寓言开场："古代有一个故事……"
   - 时事开场："最近……"
   - 形势开场："当前……"

2. **主体展开**（核心论证）
   - 对比论证：A看起来很好，但实际上……
   - 编号列举：第一……第二……第三……
   - 寓言故事化：用一个故事承载理念
   - 民间俗语化：用俗语解释抽象概念

3. **结尾设计**（留下深刻印象）
   - 排比收尾："一个……的人，一个……的人，一个……的人"
   - 号召式："让我们……"
   - 总结式："综上所述……"

### 3.5 第四步：验证与迭代

**自检清单：**

| 检查项 | 合格标准 |
|--------|---------|
| 思维模式是否贯穿全文 | 核心论点是否由所选思维模式支撑 |
| 写作技法是否正确使用 | 技法格式是否符合规范（如编号列举是否从"第一"到"第十"） |
| 逻辑是否自洽 | 分析→论证→结论是否一致 |
| 受众是否匹配 | 语言风格是否适合目标读者 |
| 说服力是否足够 | 是否有数据/案例/典故支撑 |

## 五、快速使用指南

### 5.1 一键选择流程

遇到问题时，按以下流程操作：

```
第1步：定位问题类型
  ├─ 方向性问题 → 矛盾分析法(#1)
  ├─ 突破性问题 → 灵活策略法(#11)
  ├─ 人相关问题 → 群众路线法(#2)
  └─ 长期性问题 → 持久战思维(#3)

第2步：选择写作技法
  ├─ 需要说服决策者 → 设问开场 + 对比论证
  ├─ 需要动员群众 → 寓言故事 + 排比收尾
  ├─ 需要部署工作 → 编号列举 + 先扬后抑
  └─ 需要批评问题 → 讽刺笔法 + 问答体

第3步：套用模板
  ├─ 政策分析 → 模板1
  ├─ 动员演讲 → 模板2
  ├─ 理论阐释 → 模板3
  ├─ 工作总结 → 模板4
  ├─ 批评评论 → 模板5
  ├─ 战略谋划 → 模板6
  ├─ 产品分析 → 模板7
  └─ 危机应对 → 模板8

第4步：自检
  ├─ 思维模式是否贯穿全文？
  ├─ 写作技法是否正确？
  ├─ 逻辑是否自洽？
  └─ 受众是否匹配？
```

### 5.2 技法使用速查

| 写作技法 | 最佳使用时机 | 禁忌 |
|---------|------------|------|
| 对比论证法 | 需要揭示本质、辩明是非时 | 不要只列对比，要点明对比的意义 |
| 编号列举法 | 需要部署工作、列出方案时 | 不要超过10条，否则读者记不住 |
| 排比收尾法 | 需要鼓舞士气、强化信念时 | 不要用在严肃的分析报告中 |
| 设问开场法 | 需要引发思考、引导读者时 | 不要连续设问超过3个 |
| 历史典故引用法 | 需要增加文化底蕴时 | 典故要与论点直接相关 |
| 寓言故事化 | 需要让抽象概念具体化时 | 故事要简短，寓意要明确 |
| 民间俗语化 | 需要让大众理解复杂概念时 | 不要过度使用，显得不够专业 |
| 先扬后抑法 | 需要指出问题但不打击积极性时 | 扬的部分要真诚，抑的部分要具体 |
| 问答体 | 需要增强互动感和可读性时 | 问要问到点子上，答要答到要害处 |
| 讽刺笔法 | 需要揭露问题本质时 | 讽刺要有理有据，不要人身攻击 |
