## 第二步：根据你的场景选工具

### 场景1：遇到一个问题，不知道用什么思维模式

**→ 用决策树**

打开 [docs/02-tools/thinking_mode_decision_tree.md](docs/02-tools/thinking_mode_decision_tree.md)

```
你只需要回答4个问题：
1. 问题性质？（战略/突破/人相关/长期）
2. 资源状况？（充足/紧张/极度匮乏）
3. 时间压力？（紧急/中等/充裕）
4. 关心结果？（效率/质量/创新/稳定）

→ 得到你的处境代码，比如 A-1-X-P
→ 系统推荐2-3种思维模式组合
→ 附带操作步骤和预期效果
```

### 场景2：想系统学习思维模式

**→ 先体检，再训练**

```
1. 做 [体检表](docs/02-tools/thinking_mode_health_check.md)
   → 20道题测出你的思维模式偏好和盲区
   
2. 看 [快速启动包](docs/00-quick-start/thinking_mode_quick_start.md)
   → 10分钟掌握5种核心思维模式
   
3. 选一个训练计划
   → [8周周练](docs/04-training/weekly_thinking_training.md)（每周1小时）
   → [30天训练](docs/04-training/daily_thinking_training.md)（每天30分钟）
   
4. 用 [游戏化方案](docs/04-training/thinking_mode_game.md) 增加动力
   → 41关闯关，每关有徽章
```

### 场景3：需要写一篇文章/报告

**→ 用思维→写作映射**

打开 [docs/06-ai-collaboration/thinking_to_writing_mapping.md](docs/06-ai-collaboration/thinking_to_writing_mapping.md)

```
1. 确定你要分析的问题类型
2. 查映射表，找到对应的思维模式
3. 根据思维模式，找到推荐的写作技法
4. 套用组合模板

例如：
政策分析报告 = 矛盾分析 + 对比论证 + 编号列举
动员演讲 = 群众路线 + 寓言故事化 + 排比收尾
```

### 场景4：想让AI帮你分析问题

**→ 用AI对话模板**

打开 [docs/06-ai-collaboration/thinking_mode_ai_templates.md](docs/06-ai-collaboration/thinking_mode_ai_templates.md)

```
每个模板都有填空格式，你只需要填几个空：

[问题描述] = "_____"
[背景信息] = "_____"
[约束条件] = "_____"

→ 复制模板到任意AI
→ 填好空
→ AI自动输出结构化分析
```

### 场景5：团队开会，想更高效

**→ 用会议模板**

打开 [docs/07-coaching/thinking_mode_meeting_templates.md](docs/07-coaching/thinking_mode_meeting_templates.md)

```
8种会议模板，每种都有：
- 精确到分钟的时间线
- 主持人可以直接照读的话术
- 标准化输出物格式

例如：
战略会议 = 矛盾分析 + 系统思维（90-120分钟）
复盘会议 = 批评与自我批评 + 反馈回路（60-90分钟）
```

### 场景6：想记录自己的思维成长

**→ 用日志 + 档案**

```
1. 每次用思维模式解决问题后，记录到 [应用日志](docs/07-coaching/thinking_mode_journal.md)
   → 每次记录不超过5分钟
   
2. 月底看 [月度报告](docs/07-coaching/thinking_mode_journal.md)
   → 哪种模式用得最多？成功率多少？
   
3. 年底写 [年度成长档案](docs/07-coaching/thinking_mode_evolution_portfolio.md)
   → 你的思维风格进化了多少？
```

### 场景7：想看某个行业怎么用思维模式

**→ 用行业适配指南**

打开 [docs/05-expansion/thinking_industry_adaptation.md](docs/05-expansion/thinking_industry_adaptation.md)

```
8个行业，每个行业有：
- 该行业的核心挑战
- 最常用的5种思维模式
- 行业术语 ↔ 思维模式对照表
- 2个行业专属案例
```

## 第三步：遇到问题时的急救

当你用了一种思维模式但效果不好：

**→ 打开 [应用手册](docs/03-practice/thinking_mode_user_manual.md)**

每个思维模式都有：

- ✅ 什么时候用
- 🚫 什么时候不用
- 🔧 3步诊断（方法对不对 → 执行到不到位 → 场景匹不匹配）
- 📊 效果评估指标

**→ 打开 [错题本](docs/03-practice/thinking_mode_mistake_book.md)**

50个误用案例，按4类错误分类：

- 🔴 过度使用
- 🟠 误用
- 🟡 浅尝辄止
- 🔵 模式冲突
