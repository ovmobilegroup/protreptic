# 第1周：战略思维周

> **学习目标**：学会从全局角度看问题，识别主要矛盾，制定长期竞争策略。
>
> **逻辑递进**：矛盾分析（发现问题）→ 持久战（长期视角）→ 农村包围城市（差异化切入）→ 战略预判（预见趋势）

---

### 周一：战略思维导论

#### 核心模式1：矛盾分析法（#1）
**一句话**：任何复杂系统都由多重矛盾构成，抓住主要矛盾，一切问题迎刃而解。

**思维公式**：`问题 → 识别矛盾 → 区分主次 → 抓住关键 → 解决主要矛盾 → 带动全局`

#### 核心模式2：持久战思维（#3）
**一句话**：面对强大对手或困难局面，不急于求成，通过防御→相持→反攻三个阶段逐步扭转局势。

**思维公式**：`实力对比 → 战略防御 → 战略相持 → 战略反攻 → 最终胜利`

---

### 周二：矛盾分析法练习

**🎯 场景**：你是一家中型电商公司的运营总监。近期面临四个问题：
1. 物流时效从2天延长到5天，差评率飙升
2. 两个核心运营主管同时提出离职
3. 竞品平台发起百亿补贴大战
4. 仓库库存周转率从15天恶化到28天

**💡 练习**：用矛盾分析法，在10分钟内完成：
- 列出所有矛盾
- 画出因果链（哪个问题导致哪个问题）
- 识别主要矛盾
- 给出你的优先行动方案

<details>
<summary>📝 参考答案框架</summary>

```
第一步：列出矛盾
  ├─ 物流延迟 ↔ 用户体验
  ├─ 主管离职 ↔ 运营稳定性
  ├─ 竞品补贴 ↔ 市场份额
  └─ 库存积压 ↔ 资金效率

第二步：画因果链
  库存积压（28天）→ 仓库爆满 → 拣货效率下降 → 物流延迟（5天）
  ↑                                                      ↓
  资金紧张 ← 差评率飙升 ← 用户体验差 ← 物流延迟（循环强化）
  
  主管离职 → 运营混乱 → 库存管理更差 → 加剧积压

第三步：识别主要矛盾
  → 库存积压是根因。它触发了物流、差评、资金、管理混乱。
  → 竞品补贴是外部压力，但不是内部问题的根源。

第四步：行动方案
  → 立即启动"清库存专项行动"：① 滞销品打折清仓 ② 优化采购计划 ③ 临时外包分拣
  → 1周内将库存周转从28天压到20天
  → 主管离职问题：承诺加薪+股权激励，但优先级低于清库存
  → 竞品补贴：暂不跟进，等内部稳定后再做应对
```
</details>

**🤔 反思问题**：
1. 你在生活中是否曾经"同时想解决所有问题"反而什么都没解决？那次经历教会了你什么？
2. 如何判断一个问题是"主要矛盾"还是"次要矛盾"？你的判断标准是什么？

### 周一：执行思维导论

**一句话**：一切从实际出发，理论联系实际，在实践中检验和发展真理。

#### 核心模式2：渐进改革法（#8）

### 周二：实事求是法练习

**🎯 场景**：你所在的公司连续两个季度业绩不达标。CEO在董事会上拍板："一定是员工不够努力，从下月开始实行末位淘汰制，后10%的绩效直接清零。"

你是部门负责人，对此有疑虑。请用实事求是法设计一个"一周验证方案"，看看问题到底出在哪里。

<details>
<summary>📝 参考答案框架</summary>

```
周一：直面现实，不预设立场
  → 告诉自己：CEO的说法可能完全错误，也可能部分正确。先不表态。

周二-周三：调查研究
  → 调取过去两年的数据：业绩下滑是从什么时候开始的？
  → 发现：业绩下滑始于6个月前——恰好是公司更换了CRM系统的时间点。
  → 采访10位一线销售：CRM系统导致客户数据丢失，跟进效率下降50%。

周四：理论联系实际
  → 不是"人不努力"，而是"工具不好用"。
  → 解决方案不是淘汰人，而是修复/替换CRM系统。

周五：实践检验
  → 向CEO提交报告，建议先用一周时间修复CRM，同时保留末位淘汰作为备选方案。
  → CEO同意先试运行。

一周后：修正偏差
  → CRM修复后，销售跟进效率恢复，当月业绩回升18%。
  → 末位淘汰制取消。
```
</details>

**🤔 反思问题**：
1. 你最近一次"凭直觉做判断"是什么时候？后来事实证明你的直觉对了吗？

### 周三：渐进改革法练习

</details>

  → 根因：客户流失
  → 更深一层：我们的产品质量/服务跟不上客户需求变化

  → 建立客户满意度月度追踪
  → 设置正反馈：满意度↑ → 推荐率↑ → 新订单↑
  → 设置负反馈抑制：投诉率↑ → 自动触发高层介入

  → 不依赖单一客户（最大客户占比从40%降至20%以下）

第六步：损失厌恶（竞争策略）
  → 不跟进降价（会陷入恶性循环）

### A. 思维模式选择器（快速查询）

遇到问题时，用下面的问题诊断流程快速定位合适的思维模式组合：

```
Q1：你面临的是什么性质的问题？
  [A] 方向性问题 → 战略/决策类模式
  [B] 突破性问题 → 创新/灵活类模式
  [C] 人相关的问题 → 组织/沟通类模式
  [D] 长期性问题 → 持久/渐进类模式

Q2：你的资源状况如何？
  [1] 资源充足 → 可以用更激进的策略
  [2] 资源有限 → 需要精益策略
  [3] 资源匮乏 → 需要创造性策略

Q3：时间压力有多大？
  [X] 不急 → 可以长期规划
  [Y] 一般 → 需要中期策略
  [Z] 紧急 → 需要快速反应

Q4：你最关心的结果是什么？
  [P] 赢 → 竞争导向
  [Q] 稳 → 风险导向
  [R] 长 → 可持续导向
  [S] 快 → 效率导向
```

详细诊断表请参考 `thinking_mode_selector.md`。

### B. 推荐阅读顺序

如果你想继续深入学习，建议按以下顺序：

**第一阶段（基础）**：矛盾分析法 → 实事求是法 → 系统思维法 → 渐进改革法

**第二阶段（进阶）**：战略预判法 → 持久战思维 → 多元思维模型法 → 博弈论思维

**第三阶段（高阶）**：全胜思维 → 无为而治法 → 反馈回路法 → 认知偏差识别法

**第四阶段（拓展）**：其余所有思维模式
