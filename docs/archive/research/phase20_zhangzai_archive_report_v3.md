张载是北宋五子之一、关学创始人，构建了「气一元论」的完整哲学体系：

1. **本体论奠基（M01）**：太虚即气法——以气为本体，终结有无论争
2. **辩证法核心（M02/M07）**：仇必和而解 + 一物两体——揭示矛盾统一的宇宙规律

4. **认识论突破（M04/M05）**：大心体物 + 德性之知——超越感官局限的认知方法
5. **修养论实践（M06/M10）**：变化气质 + 知礼成性——后天修养的完整路径
6. **政治哲学（M08）**：经世致用——将哲学转化为社会治理方案
7. **方法论核心（M09）**：学贵心悟——主体性思维的觉醒
