## 5. 孟子思想体系核心特点

### 5.1 与儒家其他代表人物对比

| 人物 | 核心差异 |
|------|----------|
| **孔子** | 孟子将孔子"仁"的思想系统化、形上学化；孔子重礼乐制度，孟子重内在本性 |
| **荀子** | 孟子主性善，荀子主性恶；两者形成先秦儒家两大互补传统 |
| **董仲舒** | 孟子民本贵君（民贵君轻），董仲舒天人感应佐君权（君权神授） |
| **告子** | 孟子主性善犹水就下，告子主性无善无不善犹湍水 |

### 5.2 "四端说"的理论创新

孟子以"孺子入井"思想实验论证人性本善，提出恻隐、羞恶、辞让、是非四端为道德能力的先天依据：

- 恻隐之心 → 仁之端
- 羞恶之心 → 义之端
- 辞让之心 → 礼之端
- 是非之心 → 智之端

这一理论为儒家道德形上学奠定了本体论基础，成为后世性理之学的核心源头。

### 5.3 "民贵君轻"的政治突破

孟子提出"民为贵，社稷次之，君为轻"，将政治合法性根基从"君权神授"转向"民众授权"：

- "得乎丘民而为天子"
- "天视自我民视，天听自我民听"
- 比西方社会契约论早两千余年

这一思想构成了中国古代最激进的政治平等主义宣言。

### 5.4 "浩然之气"的人格创造

孟子创造"浩然之气"这一超越性道德人格概念：

- "至大至刚，以直养而无害，则塞于天地之间"
- "配义与道"——必须与义和道配合
- 非气功或神秘主义，乃长期道德实践形成的人格力量

这一概念成为后世士人精神的核心，影响深远。
