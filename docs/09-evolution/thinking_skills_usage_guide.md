## 二、技能加载方式

### 方式1：自动加载（推荐）

所有工具在启动时自动加载 `docs/09-evolution/` 目录，加载所有有效的 本体文档 文件。无需手动操作。

### 方式2：手动指定加载

启动新会话时指定特定技能：

```bash
hermes -s ultimate-thinking-and-writing-methods
hermes -s four-writers-writing,maozedong-writing
hermes -s ultimate-thinking-and-writing-methods,four-writers-writing,maozedong-writing
```

### 方式3：会话内加载

在 Hermes 会话中使用斜杠命令：

```
/skill ultimate-thinking-and-writing-methods
/skill four-writers-writing
/skill maozedong-writing
```

### 方式4：技能列表查看

```bash
hermes skills list
```

## 三、各技能详细说明

### 1. ultimate-thinking-and-writing-methods（终极思维模式与写作技法）

**核心能力**：32种通用思维模式 + 10种通用写作技法 + 一键诊断

**适用场景**：

- 复杂问题分析与战略决策
- 创新突破与长期竞争
- 团队建设与管理
- 危机应对与商业竞争
- 各类文体写作

**关键功能**：

- **问题诊断流程**：通过4个关键问题快速定位处境
- **16种问题分类详解**：每个分类都有推荐思维模式组合和操作步骤
- **思维模式混搭指南**：跨领域组合 > 同一领域组合
- **速查表**：32种思维模式 + 10种写作技法快速检索

**推荐用法**：遇到问题时，先用诊断流程定位，再选择思维模式组合，按步骤执行。

### 2. four-writers-writing（四大笔杆子写作范式）

**核心能力**：四种经典写作范式的可迁移方法论

**四种范式**：
| 范式 | 核心能力 | 适用场景 |
|------|---------|---------|
| 胡乔木（系统化整理） | 从碎片到体系 | 政策文件、理论文章、会议纪要 |
| 陈伯达（批判分析） | 理论批驳 | 辩论、评论、舆论斗争 |
| 田家英（实证调查） | 数据说话 | 调研报告、政策建议、用户研究 |
| 胡绳（历史纵深） | 以史为鉴 | 战略分析、学术研究、行业报告 |

**推荐用法**：根据素材来源和写作目标选择主导范式，可组合使用多种范式。

### 3. maozedong-writing（毛泽东写作技法）

**核心能力**：基于237篇文章分析的写作方法论

**关键内容**：

- **六大思维模式**：矛盾分析、调查研究、群众路线、战略预判、辩证思维、政策灵活
- **十大写作技法**：对比论证、编号列举、排比收尾、设问开场、历史典故、寓言故事化、民间俗语化、先扬后抑、问答体、讽刺笔法
- **四种结构框架**：问题分析型、战略部署型、政治动员型、理论阐述型
- **跨阶段演变**：从1920s到1950s的写作风格变化规律
- **经典名句汇编**：按主题分类的名言警句

**适用场景**：政策分析报告、形势研判、工作部署、理论阐释、群众动员、工作总结

## 五、快速启动清单

### 使用思维模式技能时：

1. **明确问题类型**：方向性/突破性/人相关/长期性
2. **评估资源状况**：充足/有限/匮乏
3. **判断时间压力**：不急/一般/紧急
4. **确定核心目标**：赢/稳/长/快
5. **选择思维模式组合**：参考一键诊断或速查表
6. **按步骤执行**：每个分类都有详细操作步骤
7. **复盘总结**：哪些模式有效，哪些需要调整

### 使用写作技法技能时：

1. **确定素材来源**：讲话/访谈 → 胡乔木；对立观点 → 陈伯达；真实情况 → 田家英；长期视角 → 胡绳
2. **确定写作目标**：整理呈现 → 系统化；说服改变 → 批判化；揭示真相 → 实证化；深度洞察 → 历史化
3. **选择主导范式**：先确定一个主导范式
4. **组合辅助范式**：大多数高质量写作需要两种以上范式
5. **参考经典案例**：每个范式都有实战案例可借鉴

## 七、注意事项

1. **技能自动加载**：所有技能在 `docs/09-evolution/` 目录下，Hermes Agent 会自动加载，无需手动配置
2. **本体文档 格式**：每个技能必须包含 YAML frontmatter（name + description），否则不会被识别
3. **文件大小**：本体文档 超过 20,000 字符会被截断，建议拆分到多个技能或引用文件
4. **技能优先级**：同名技能按目录层级加载，子目录中的技能优先于扁平目录
5. **跨技能组合**：不同技能的内容可以互补，建议根据场景组合使用
