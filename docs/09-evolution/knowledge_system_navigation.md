## 第一部分：身份 → 文件路径推荐系统

> **使用方法**：确认你的身份标签，找到对应路径，按顺序执行。

---

### 🚀 路径 A：创业者

**适合**：正在创业/准备创业/做产品的人

```
起点：thinking_mode_quick_start.md（10分钟建立认知）
  │
  ├─→ 第1步：快速启动包
  │    时间：10分钟
  │    目标：知道这是什么、怎么用
  │    产出：能说出核心思维模式的一句话
  │
  ├─→ 第2步：decision_tree（决策树）
  │    时间：5分钟
  │    目标：定位你的创业处境（方向/突破/资源/时间）
  │    产出：你的"处境代码" + 推荐的思维模式组合
  │
  ├─→ 第3步：case_library（案例库）→ 创业类案例
  │    时间：15-30分钟
  │    目标：看别人怎么用的
  │    产出：可借鉴的具体做法
  │
  ├─→ 第4步：user_manual（应用手册）→ 创业相关章节
  │    时间：按需
  │    目标：遇到问题时查"什么时候用/什么时候不用"
  │    产出：正确的使用方式
  │
  └─→ 终点：能独立用2-3种思维模式做创业决策
       验证：health_check（体检表）≥ 60分
```

**条件判断**：
- 如果资源紧张（< 5万启动资金）→ 重点看 `cross_domain_expansion.md` #4 农村包围城市思维
- 如果需要融资 → 重点看 `selector` 中的"方向性问题"分支
- 如果产品卡住了 → 重点看 `decision_tree` 中"突破性问题"分支
- 如果想快速验证想法 → 直接跳到 `quick_start` 的"1小时实战演示"

---

### 👔 路径 B：管理者

**适合**：团队领导/项目经理/部门主管/CEO

```
起点：thinking_mode_coach_guide.md（教练指南）
  │
  ├─→ 第1步：coach_guide（教练指南）
  │    时间：20分钟
  │    目标：学会引导团队思考，而非直接给答案
  │    产出：5步教练流程 + 话术库
  │
  ├─→ 第2步：decision_tree（决策树）
  │    时间：5分钟
  │    目标：定位团队管理中的问题类型
  │    产出："人相关问题"分支的推荐组合
  │
  ├─→ 第3步：case_library（案例库）→ 管理类案例
  │    时间：15-30分钟
  │    目标：看管理场景的真实案例
  │    产出：可复用的管理模板
  │
  ├─→ 第4步：user_manual（应用手册）→ 团队/组织章节
  │    时间：按需
  │    目标：查具体场景的正确用法
  │    产出：诊断 + 纠偏
  │
  └─→ 终点：能用思维模式框架带团队、做决策
       验证：mistake_book（错题本）无重大误用
```

**条件判断**：
- 如果团队效率低 → 重点看 `coach_guide` 的"团队建设"场景 + `decision_tree` 的 C-1-Y/P
- 如果要做组织变革 → 重点看 `cross_domain_expansion` #8 渐进改革法
- 如果要培养下属 → 重点看 `coach_guide` 的"教练角色定位"
- 如果处理冲突 → 重点看 `decision_tree` 的 C-2-Z/P（冲突调解）

### 📚 路径 C：学习者

**适合**：学生/转行者/想系统提升思维能力的人

```
起点：thinking_mode_quick_start.md（快速启动包）
  │
  ├─→ 第1步：quick_start（快速启动包）
  │    时间：30分钟（3min了解 + 10min上手 + 1hr实战）
  │    目标：建立整体认知 + 掌握5种核心思维 + 2种写作技法
  │    产出：能分析一个小问题并写出报告
  │
  ├─→ 第2步：daily_training（30天训练计划）
  │    时间：每天15-30分钟 × 30天
  │    目标：系统性提升思维能力
  │    产出：30天的刻意练习记录
  │    │
  │    └─→ 如果觉得30天太长 → 改用 weekly_training（8周周练）
  │
  ├─→ 第3步：health_check（体检表）
  │    时间：10分钟
  │    目标：了解自己的思维画像
  │    产出：你的思维优势 + 待提升领域
  │
  ├─→ 第4步：mistake_book（错题本）
  │    时间：按需
  │    目标：检查自己是否在用错方法
  │    产出：纠正后的正确用法
  │
  └─→ 终点：形成自己的思维模式组合习惯
       验证：能独立用3-4种模式分析复杂问题
```

**条件判断**：
- 如果时间很少 → 只做 `quick_start` + `dictionary`（口袋书）
- 如果想快速见效 → 重点练 `quick_start` 的"1小时实战"
- 如果想系统进阶 → 按 `daily_training` 的30天计划走
- 如果想轻松一点 → 用 `game`（游戏化闯关）代替训练计划

  ├─→ 第2步：cross_domain_expansion_1~7（跨领域扩展）
  │    时间：按领域选择性阅读
  │    目标：建立跨学科思维框架
  │    产出：经济学/心理学/工程学/生物学/教育学/社会学/AI/法学

  │    时间：30分钟

  │
  ├─→ 第4步：comparison_matrix（对比矩阵）
  │    时间：20分钟
  │    目标：理解81对思维模式的关系

- 如果关注思想史 → 重点读 `world_spectrum` + `four_writers`
- 如果关注跨学科 → 按顺序读 `cross_domain_1` → `cross_domain_7`
- 如果需要写论文 → 重点看 `four_writers_comparison` + `bilingual`
- 如果想做模式关系研究 → 重点看 `comparison_matrix`

### 🆘 问题类型 1：遇到问题，不知道用什么方法

```
起点：selector（思维模式选择器）或 decision_tree（决策树）
  │
  ├─→ 快速诊断：selector（4个诊断问题 → 推荐3种组合）
  │    时间：5分钟
  │    适用：简单问题，需要快速答案
  │
  ├─→ 精细诊断：decision_tree（4道选择题 → 20种场景）
  │    时间：5分钟
  │    适用：复杂问题，需要精准推荐
  │
  ├─→ 查看案例：case_library → 找同类问题的解决方案
  │    时间：10-20分钟
  │    适用：想看别人怎么处理类似问题
  │
  ├─→ 深入方法：ultimate_handbook → 查看推荐思维模式的详细说明
  │    时间：按需
  │    适用：想深入了解某种思维模式
  │
  └─→ 验证：user_manual → 确认使用方式正确
       时间：5分钟
```

**条件判断**：
- 如果问题简单（≤1天决策）→ 跳过诊断，直接看 `dictionary` 速查
- 如果问题复杂（多方利益冲突）→ 用 `decision_tree` 的"A-方向性问题"分支
- 如果问题紧急（24小时内要解决）→ 用 `user_manual` 的"急救指南"
- 如果问题模糊（不知道是什么问题）→ 用 `selector` 的"问题分类"功能

  │    时间：10分钟
  │    目标：了解自己的思维优势 + 待提升领域
  │    产出：你的"思维画像"报告
  │

  │    时间：15分钟
  │    目标：检查自己是否在重复犯错
  │    产出：已发现的误用列表
  │
  ├─→ 第3步：coach_guide（教练指南）
  │    时间：20分钟
  │    目标：学会自我引导和他人指导
  │    产出：5步教练流程
  │
  ├─→ 第4步：training（训练计划）
  │    时间：持续

- 如果想系统提升 → 按 `daily_training` 30天计划
- 如果想教别人 → 重点看 `coach_guide`
- 如果想追踪进度 → 用 `journal` 记录 + 定期 `health_check`

## 第五部分：使用原则

### 原则1：组合使用 > 单一使用

没有任何一种思维模式能解决所有问题。

> **黄金三角**：矛盾分析法(#1) + 渐进改革法(#8) + 反馈回路法(#29)
> → 几乎适用于所有复杂问题

### 原则2：先诊断，再选择

不要盲目套用思维模式。

> 遇到问题 → 先用 `selector` 或 `decision_tree` 诊断 → 再选择组合

### 原则3：写作与思维并重

写作不是文字的堆砌，而是思维的显化。

> 想不清楚就写不出来，写不出来就是没想清楚

### 原则4：持续迭代

这套知识库不是终点，而是起点。

> 随着使用，你会发现自己可以：补充新模型、反馈实战经验、发明自己的"混搭组合"

### 原则5：身份可变，路径互通

你不是固定一种身份。创业者也需要学习，研究者也需要写作。

> 当身份变化时，切换到对应路径即可。所有路径的起点都是 `quick_start`。
