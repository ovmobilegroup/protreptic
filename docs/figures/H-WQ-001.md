## 四、caveats（5条）

1. '杀妻求将'叙事存疑：《史记》孤证，《韩非子·外储说》另有版本
2. 今本《吴子》六篇为托辑混合，《汉志》四十八篇已佚——引文须多书互证
3. 阴晋之战兵力对比属夸饰性文本，以寡击众成立、具体数字不可直接引用
4. 楚变法成效（南平百越等）多系宛守与西河时期战功，时间仅一年余，因果不能混写
5. 伏尸殉法仅《吕氏春秋·贵卒》独载，'设计性'解读系方法论重构，须与'情急之生'并注

## 五、方法论签名（各模式一句话）

- M-WQ-001：选拔与激励是同一台机器的两半——公开硬标准 + 家庭级持久特权
- M-WQ-002：文德与武备互补且不可让渡，单轨即溃
- M-WQ-003：'可击'与'勿击'对称清单 + 机会窗口化，判断从勇气改写为核对清单
- M-WQ-004：上级先单方面支付可见成本（让渡特权），换取下级超额投入的互惠契约
- M-WQ-005：士气是被结构（教戒、信号、军法）制造的可计算参数，像粮草一样分相管理
- M-WQ-006：'因形用权'——预案库 + 按态势归类 + 即席裁量，最早的 if-then 决策树之一
- M-WQ-007：信用先于内容——赏不过宿、罚不逾时、法不阿贵，一次失信折损远超一次慷慨
- M-WQ-008：战斗力是任务形状与兵力形状的匹配度，将领的核心工作是做匹配器
- M-WQ-009：将领是对君/对士/对敌/对己四界面的耦合器，最难的审计格是自我（吴起本人的负面注脚）
- M-WQ-010：变法是利益存量再分配，成败不在方案而在能否活过庇护人——承重结构缺失则只能以身殉法
