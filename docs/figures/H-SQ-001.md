# 司马迁 (Sima Qian) - 史学方法论奠基者

## 基本信息
- **姓名**: 司马迁 (Sīmǎ Qiān)
- **字**: 子长 (Zǐcháng)
- **号**: 史圣
- **生卒年**: 前145年 - 前86年
- **时代**: 西汉
- **学派**: 史学
- **主要著作**: 《史记》、《太史公自序》、《报任安书》

## 历史地位
中国史学奠基人，《史记》作者，开创纪传体史书体例。曾任太史令，因李陵事件受腐刑，发愤著书完成《史记》一百三十篇，五十二万字，记载上至黄帝下至汉武帝三千年的历史。提出"究天人之际，通古今之变，成一家之言"的史学纲领，建立以人物为中心的历史叙事方法，开创中国史学传统。

## 核心思想
1. **纪传体创制法** - 以人物为中心的历史叙事框架
2. **究天人之际法** - 探究天道与人事关系的哲学维度
3. **通古今之变法** - 贯通三千年历史的整体观
4. **善述不善作法** - 尊重史实的史学伦理
5. **发愤著书法** - 苦难转化为创作动力
6. **探赜索隐法** - 深入挖掘历史真相
7. **人文叙事法** - 以个体命运映照时代变迁

## 思维模式详解

### M301: 纪传体创制法
**定义**: 创制以人物为中心的纪传体史书体例，将本纪（帝王）、世家（诸侯）、列传（人物）、书（典章制度）、表（年月世系）五体合一，打破编年体局限。

**核心概念**: 纪传体、本纪、世家、列传、书、表、人物中心

**现代应用**: 人物传记写作、历史研究组织、个人发展史构建

### M302: 究天人之际法
**定义**: 探究天道自然规律与人事社会发展之间的辩证关系，建立历史哲学维度，理解历史发展中的必然性与偶然性、规律性与能动性的统一。

**核心概念**: 天人关系、天道、人事、历史哲学、必然性、偶然性

**现代应用**: 历史哲学研究、社会发展预测、政策制定分析

### M303: 通古今之变法
**定义**: 纵向贯通上下三千年历史，横向囊括政治、经济、文化、军事等多领域，识别历史演进规律，建立完整的历史发展观。

**核心概念**: 古今贯通、多领域分析、历史规律、演进模式、整体观

**现代应用**: 历史趋势分析、社会发展研究、战略规划制定

### M304: 善述不善作法
**定义**: 传承历史记载的规范和传统，尊重史实，不随意创作和虚构，保持客观中立的史学态度，以传承历史真相为首要任务。

**核心概念**: 史实尊重、客观中立、传承规范、不虚构、史学伦理

**现代应用**: 学术研究规范、历史教育方法、新闻报道原则

### M305: 发愤著书法
**定义**: 将个人苦难和挫折转化为创作动力，忍辱负重，坚持完成历史使命，以"文王拘而演周易，仲尼厄而作春秋，屈原放逐乃赋离骚"的精神激励自己。

**核心概念**: 发愤、忍辱负重、创作动力、精神激励、历史使命

**现代应用**: 逆境创作心理学、精神动力培养、历史使命感教育

### M306: 探赜索隐法
**定义**: 深入挖掘历史真相，探究事物的本质和深层原因，钩深致远，通过细致的史料考证和逻辑分析还原历史本来面目。

**核心概念**: 探赜索隐、钩深致远、史料考证、逻辑分析、还原真相

**现代应用**: 历史研究方法、社会现象分析、问题根源探究

### M307: 人文叙事法
**定义**: 以个体命运映照时代变迁，通过生动的人物描写和故事叙述展现历史，建立史家主体性，使历史叙述具有人文关怀和文学价值。

**核心概念**: 个体命运、时代变迁、人文关怀、文学价值、史家主体性

**现代应用**: 历史文学创作、人物传记写作、历史教育方法

## 历史影响
1. **确立中国史学基本范式** - 纪传体成为后世正史标准体例
2. **开创人物中心叙事传统** - 建立以人物为核心的历史叙事方法
3. **建立史学评价标准** - "史才、史学、史识"的史学理论体系
4. **影响后世文人创作** - "发愤著书"精神成为文人创作动力
5. **文学与史学双重价值** - 《史记》被鲁迅誉为"史家之绝唱，无韵之离骚"

## 跨学科关联
- **与儒家思想**: 继承孔子"述而不作"的史学传统
- **与哲学思想**: 建立历史哲学维度，探讨天人关系
- **与文学传统**: 开创文史结合的叙事风格
- **与现代史学**: 为现代历史研究提供方法论基础

## 现代启示
司马迁的史学方法论对当代研究和创作具有重要启示：
- **客观真实性** - 尊重事实，避免虚构
- **系统性思维** - 多维度分析历史现象
- **人文关怀** - 关注个体命运与时代关系
- **创新精神** - 在传统基础上开创新方法
- **坚韧品格** - 在逆境中坚持完成使命
