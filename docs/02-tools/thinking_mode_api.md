## 1. API 概述

思维模式 API 是一个**问题诊断 → 模式匹配 → 行动建议**的工具系统。

```
用户输入（自然语言问题）
        ↓
  系统分类（问题类型 + 资源 + 时间 + 目标）
        ↓
  模式匹配（推荐 2-4 个思维模式）
        ↓
  输出建议（操作步骤 + 预期效果 + 实战案例）
```

### 设计原则

- **自然语言优先**：用户只需描述问题，不需要记住命令
- **快捷指令可选**：熟练用户可用 `/analyze`、`/train` 等命令加速
- **输出标准化**：每次返回结构一致的诊断报告
- **可组合扩展**：支持多模式混搭，覆盖复杂场景

## 2. 用户输入格式

### 2.1 自然语言输入（推荐）

用户直接用日常语言描述问题，系统自动分类匹配。

```
示例：
"我的创业公司面对大厂竞争，资源很少，该怎么突围？"
"团队最近效率很低，士气也不高，怎么解决？"
"我想学一门新技能，但总是半途而废。"
```

### 2.2 结构化输入（精确匹配）

用户可主动提供 4 维诊断码，获得更精准的推荐。

```
[A] 问题性质: 方向性(B) | 突破性(C) | 人相关(D) | 长期性(E)
[1] 资源状况: 充足(1) | 有限(2) | 匮乏(3)
[X] 时间压力: 不急(X) | 一般(Y) | 紧急(Z)
[P] 目标导向: 赢(P) | 稳(Q) | 长(R) | 快(S)
```

### 2.3 快捷指令输入

```
/analyze [问题描述]          → 推荐思维模式组合
/train [模式名称]            → 该模式的练习题
/mistake [模式名称]          → 该模式的常见误用
/lookup [关键词]             → 搜索匹配的思维和技法
/combo [场景描述]            → 推荐混搭组合
/writing [文体]              → 推荐写作技法和结构框架
/diagnose                    → 启动交互式诊断流程
```

## 4. 快捷指令系统

### 4.1 `/analyze` — 问题诊断

```
用法: /analyze [问题描述]
或:   /analyze [A1X/P]  ← 直接传入诊断码

输出:
├── 问题分类: xxx
├── 推荐模式: #1 矛盾分析法 + #7 战略预判法
├── 操作步骤: 1, 2, 3, 4, 5
├── 预期效果: 3条
└── 实战案例: 简短案例
```

**示例：**

```
/user: /analyze 我的创业公司资源有限，面对大厂竞争不知道怎么突围
/system:
  ▸ 问题分类: 长期竞争 + 商业竞争
  ▸ 推荐组合: #3 持久战思维 + #4 农村包围城市思维 + #16 游击战十六字诀
  ▸ 操作步骤:
    1. 评估实力对比（持久战）→ 诚实面对差距，进入防御阶段
    2. 找到薄弱市场（农村包围城市）→ 巨头看不上的细分市场
    3. 建立根据地 → 在该细分市场做到第一
    4. 灵活机动（游击战）→ 敌进我退，敌驻我扰，敌疲我打，敌退我追
  ▸ 预期效果: 1年内站稳脚跟，3年建立优势，5年具备正面竞争能力
  ▸ 案例: 拼多多在阿里京东垄断下，从下沉市场切入，成为第二大电商
```

### 4.2 `/train` — 模式练习

```
用法: /train [思维模式名称]
或:   /train [模式编号]

输出:
├── 模式简介
├── 练习题目（3道情景题）
├── 参考答案
└── 自评标准
```

**示例：**

```
/user: /train 矛盾分析法
/system:
  ▸ 模式: #1 矛盾分析法 — 抓住关键，带动全局
  ▸ 练习1: 你负责的项目同时面临进度延迟、预算超支、人员流失三个问题，
           请识别主要矛盾并说明理由。
  ▸ 练习2: 一家传统制造企业面临电商冲击，请列出至少5对矛盾，
           并按主次排序。
  ▸ 练习3: 你发现团队效率低，但不知道原因。如何用矛盾分析法找到根因？
  ▸ 自评: 能否准确区分主要矛盾和次要矛盾？能否识别矛盾之间的因果关系？
```

### 4.3 `/mistake` — 错题查询

```
用法: /mistake [思维模式名称]
或:   /mistake [模式编号]

输出:
├── 过度使用型错误
├── 误用型错误
├── 浅尝型错误
└── 纠正方法
```

**示例：**

```
/user: /mistake 系统思维法
/system:
  ▸ 过度使用: 画出系统图后不做决策 → 纠正: 系统图必须配行动方案
  ▸ 误用场景: 简单问题用系统思维 → 纠正: 简单问题用2-3步即可
  ▸ 浅尝错误: 只画因果图，不标注杠杆点 → 纠正: 每个图必须标出3个杠杆点
```

### 4.4 `/lookup` — 关键词搜索

```
用法: /lookup [关键词]

输出:
├── 匹配的思维模式（最多5个）
├── 匹配的写作技法（最多3个）
└── 相关混搭组合
```

**示例：**

```
/user: /lookup 谈判
/system:
  ▸ 思维模式: #13 全胜思维 + #20 博弈论思维 + #31 框架效应法
  ▸ 写作技法: 问答体（技法9）
  ▸ 混搭组合: 💬 沟通组合 = 框架效应法 + 双系统思维 + 启发式教学法
```

### 4.5 `/combo` — 混搭推荐

```
用法: /combo [场景描述]

输出:
├── 推荐混搭组合
├── 每个模式的作用
├── 为什么这样组合
└── 操作步骤（整合版）
```

### 4.6 `/writing` — 写作指导

```
用法: /writing [文体/场景]

输出:
├── 推荐写作技法
├── 推荐结构框架
├── 写作公式
└── 示例片段
```

**示例：**

```
/user: /writing 战略分析报告
/system:
  ▸ 开场: 设问开场法（技法4）— "我们的战略要继续走大而全的道路吗？不对。"
  ▸ 主体: 对比论证法（技法1）+ 编号列举法（技法2）
  ▸ 结尾: 号召式排比收尾（技法3）
  ▸ 结构: 问题分析型框架（1-5步）
```

### 4.7 `/diagnose` — 交互式诊断

```
用法: /diagnose

输出: 启动4步问答流程
  Q1: 你面临的是什么性质的问题？
  Q2: 你的资源状况如何？
  Q3: 时间压力有多大？
  Q4: 你最关心的结果是什么？
  → 根据回答输出推荐组合
```

### 4.8 快捷指令速查表

| 指令 | 功能 | 参数 | 输出 |
|------|------|------|------|
| `/analyze` | 问题诊断 | 自然语言或诊断码 | 推荐模式 + 步骤 + 案例 |
| `/train` | 模式练习 | 模式名称或编号 | 练习题 + 参考答案 |
| `/mistake` | 错题查询 | 模式名称或编号 | 常见错误 + 纠正方法 |
| `/lookup` | 关键词搜索 | 关键词 | 匹配模式 + 技法 + 组合 |
| `/combo` | 混搭推荐 | 场景描述 | 混搭组合 + 操作步骤 |
| `/writing` | 写作指导 | 文体/场景 | 技法 + 结构 + 示例 |
| `/diagnose` | 交互式诊断 | 无 | 4步问答 → 推荐组合 |

## 10. 常见错误速查

| 模式 | 过度使用表现 | 纠正方法 |

| #16 游击战 | 资源充足的竞争 | 改用正面作战思维 |
