# 🧠 思维模式体检表

> **做一次有趣的思维扫描——20道题测出你的思维优势区和盲区**

---

## 📋 使用说明

1. 找一张纸，准备一支笔
2. 逐题阅读，选出**最符合你本能反应**的选项（第一直觉最重要！）
3. 每题只选一个，不要犹豫太久
4. 完成后对照计分表统计各选项数量
5. 读取你的思维画像

> ⏱️ 预计用时：10-15分钟
> 🎯 记住：没有"正确答案"，只有"你的答案"

---

## ✍️ 20道情景选择题

### 第1题：团队项目连续延期，作为负责人你第一反应是？

- **A.** 召集大家开"无责复盘会"，每个人先说自己哪里没做好，然后一起找根因 → 📊 批评与自我批评法
- **B.** 列出所有问题，按严重程度排序，找到"如果不解决，其他都会跟着完蛋"的那个 → 🔍 矛盾分析法
- **C.** 先停下手头所有非紧急工作，派一个人去产线跟班一天，搞清楚真实瓶颈在哪 → 📏 实事求是法
- **D.** 把大目标拆成多个小里程碑，每个里程碑设置明确的可衡量指标，每周检查进度 → 🎯 目标管理法

---

### 第2题：公司要进入一个全新市场，竞争对手已经在里面站稳了，你会怎么做？

- **A.** 找对手服务最差的细分客户群，集中所有资源做到那个小市场的绝对第一 → 🏘️ 农村包围城市思维
- **B.** 从多个角度分析：用经济学看供需、用心理学看用户决策、用军事看竞争格局 → 🧩 多元思维模型法
- **C.** 不正面硬拼，设计一个对手"必须赢但你不需要赢"的差异化方案，以最小代价胜出 → 🕊️ 全胜思维
- **D.** 先做小规模试点，跑通一个场景后再逐步推广，边做边调整 → 🐢 渐进改革法

---

### 第3题：你发现自己最近工作效率很低，经常加班但产出一般，你会怎么破局？

- **A.** 列出所有在做的事情，找出那个"牵一发而动全身"的核心问题，集中火力解决它 → 🔍 矛盾分析法
- **B.** 画一张全局关系图，看看哪些事是正反馈（做了就有更多动力），哪些是负反馈（做了反而更累） → 🔄 反馈回路法
- **C.** 诚实地问自己：我擅长什么？喜欢什么？需要什么？这三个的交集就是我的方向 → 🧘 无为而治法
- **D.** 先假设"我现在的做法全错了"，然后逐一反驳——如果继续这样下去，半年后会怎样？ → 🔙 逆向思维（多元思维模型法的一部分）

---

### 第4题：老板给你分配了一个几乎不可能完成的KPI，你的第一反应是？

- **A.** 拆解这个KPI，看哪些部分是可以通过优化流程实现的，哪些需要额外资源 → 📐 边际思维
- **B.** 先不急着接或不接，分析一下：这个KPI背后的真正意图是什么？老板在担心什么？ → 🤝 统一战线法
- **C.** 接受KPI，但制定一个"三步走"计划——先拿一个小胜利证明可行性，再逐步扩大 → ⏳ 持久战思维
- **D.** 去找几个同事聊聊，看看他们是怎么理解这个KPI的，收集多方意见后再做判断 → 👥 群众路线法

---

### 第5题：你正在为一个重要决策纠结，两个方案各有优劣，你会怎么处理？

- **A.** 列出每个方案的最好/最坏/最可能结果，推演1年后、3年后、5年后会怎样 → 🔮 战略预判法
- **B.** 强制自己站在对方立场想：如果我是反对这个方案的人，我会怎么说？ → 🪞 认知偏差识别法
- **C.** 找一个从未接触过这个问题的朋友，让他听听两个方案的优缺点，看他的第一反应 → 🌍 统一战线法
- **D.** 先做决定，然后在执行中不断微调——边走边看，随时准备转向 → 🦎 灵活策略法

---

### 第6题：你的一个好朋友最近状态很差，工作失恋双打击，你会怎么帮他？

- **A.** 先不急着给建议，安静听他说，让他自己找到答案——有时候"不干预"就是最好的帮助 → 🧘 无为而治法
- **B.** 帮他列出所有困扰，区分"能改变的"和"不能改变的"，集中精力解决能改变的部分 → 🔍 矛盾分析法
- **C.** 约他一起做一件完全不同的事（爬山/看电影/运动），先让状态好转再说 → 🦎 灵活策略法
- **D.** 分享你自己曾经经历的低谷和怎么走出来的，用亲身经历给他希望 → 👥 群众路线法（从实践者中来）

---

### 第7题：公司要推出一款新产品，但研发、市场、销售三个部门意见不一，你会？

- **A.** 把三个部门负责人拉到一起，让他们各自说出最担心的问题，找到共同目标 → 🤝 统一战线法
- **B.** 先让每个部门独立出一个方案，然后放在一起比较，看哪个方案的预期收益最大 → 📐 边际思维
- **C.** 让一线销售人员先去和客户聊，把客户的真实需求带回来，用数据说话 → 👥 群众路线法
- **D.** 不追求完美方案，先出一个最小可行版本（MVP），上线后根据市场反馈再迭代 → 🐢 渐进改革法

---

### 第8题：你打算学一门全新的技能（比如编程、设计、外语），你会怎么规划？

- **A.** 先花一周时间广泛了解这个领域的核心概念和框架，建立"思维格栅" → 🧩 多元思维模型法
- **B.** 设定一个具体的项目目标（比如"3个月做出一个网站"），在做中学 → 🎯 目标管理法
- **C.** 找3个不同方向的入门教程同时开始，每个试两周，看哪个最适合自己 → 🌱 自然选择法
- **D.** 制定一个渐进的学习路径：第1个月打基础，第2个月做小项目，第3个月进阶 → ⏳ 持久战思维

---

### 第9题：你在社交媒体上看到一条和你观点完全相反的热帖，你的反应是？

- **A.** 先停下来想想：我为什么会这么反感？是不是触发了我的某种认知偏差？ → 🪞 认知偏差识别法
- **B.** 仔细看完对方的论点，试着找出其中最有道理的部分，哪怕只有一点点 → 🔍 矛盾分析法（找主要论点）
- **C.** 不急着反驳，先理解对方为什么会这么想——他的背景和经历可能和我完全不同 → 🌍 总体性思维
- **D.** 把这个帖子当成一次"框架效应"的实验：同样的观点，如果用不同的方式表达，我会不会接受？ → 🖼️ 框架效应法

---

### 第10题：你负责的项目突然遇到重大技术障碍， deadline就在下周，你会？

- **A.** 立即召集核心成员，要求只说事实不谈猜测，写下"现在到底发生了什么" → 📏 实事求是法
- **B.** 列出所有可能的解决方案，每个方案标注风险等级和所需时间，选一个折中方案 → 🦎 灵活策略法
- **C.** 承认这个技术难点短期内无法攻克，和客户沟通延期或缩小范围 → 🤝 统一战线法（和利益相关方协调）
- **D.** 启动B计划——有没有什么替代方案可以绕开这个技术障碍？ → 🧩 多元思维模型法（逆向思考）

---

### 第11题：你有一个绝佳的创业想法，但没有资金没有人脉，你会怎么做？

- **A.** 先找一个足够小的细分市场，在这个小池塘里做到第一，积累口碑和资源 → 🏘️ 农村包围城市思维
- **B.** 做一个最小可行性产品（MVP），用最低成本验证市场需求 → 🐢 渐进改革法
- **C.** 去找那些和你有同样想法但还没行动的人，组建一个临时团队一起干 → 🤝 统一战线法
- **D.** 先不急着启动，花一个月时间调研：这个市场真的有需要吗？竞争对手是谁？ → 📏 实事求是法

---

### 第12题：你在一次重要演讲前非常紧张，手心出汗、心跳加速，你会怎么调节？

- **A.** 承认紧张是正常的，把注意力从"我表现好不好"转移到"我能给听众带来什么价值" → 🖼️ 框架效应法（重构框架）
- **B.** 深呼吸，告诉自己：系统1（直觉）在报警，但系统2（理性）知道这没什么可怕的 → 🧠 双系统思维
- **C.** 提前到场，熟悉环境，和前排观众聊几句，把陌生感变成熟悉感 → 📏 实事求是法（直面现实）
- **D.** 把演讲内容拆成小块，每天练一部分，练到形成肌肉记忆 → ⏳ 持久战思维（分阶段准备）

---

### 第13题：你发现团队里有两个核心成员关系不和，经常暗中较劲，你会？

- **A.** 分别和他们一对一谈话，了解各自的顾虑，找到矛盾的根源 → 👥 群众路线法（深入实践）
- **B.** 在他们之间找一个共同的外部挑战或目标，把注意力从内耗转向对外 → 🤝 统一战线法
- **C.** 不急着调解，先观察一段时间——有时候适度的竞争反而能提升团队活力 → 🌱 自然选择法
- **D.** 重新设计他们的职责范围，减少重叠和冲突点，从制度上化解矛盾 → ⚖️ 程序正义法

---

### 第14题：你买了一套房，装修时发现了很多隐蔽问题（漏水、电路老化等），你会？

- **A.** 先全面排查所有可能的问题，列一个清单，按紧急程度和成本排序 → 🔍 矛盾分析法
- **B.** 找3-5个装修公司报价，但不要只看总价，要看每个方案的边际性价比 → 📐 边际思维
- **C.** 先解决最紧急的漏水问题，其他问题边住边修，不追求一次性完美 → 🐢 渐进改革法
- **D.** 请一个独立第三方检测机构出具报告，用专业数据来决定维修方案 → 📏 实事求是法

---

### 第15题：你正在考虑是否要跳槽，新工作的薪资涨了30%但工作强度也大很多，你会？

- **A.** 画一张决策关系图：薪资增长→生活质量变化→健康影响→长期职业发展，看看整体是正还是负 → 🔄 反馈回路法
- **B.** 先做最坏的打算：如果新工作干了一年就辞职，我损失了什么？能得到什么？ → 🔙 逆向思维（多元思维模型法）
- **C.** 找已经在类似公司工作的人聊聊，了解真实的日常状态，而不是只看JD上的描述 → 👥 群众路线法
- **D.** 给自己设定一个"试用期"：接受offer，干6个月，不合适再走，灵活应变 → 🦎 灵活策略法

---

### 第16题：你写了一份重要的方案/报告，写完回头看觉得自己写得一团糟，你会？

- **A.** 先放一边，去做别的事，过几个小时或第二天再看，用新鲜的眼光重新审视 → 🧘 无为而治法（顺应自然节奏）
- **B.** 把方案的核心论点用一句话写出来，然后逐段检查：每一段是否都在支撑这句话？ → 🔍 矛盾分析法（找主线）
- **C.** 发给两个不同背景的朋友看，问他们"看完之后你最记住的是什么"，而不是"你觉得哪里不好" → 🖼️ 框架效应法（重构反馈方式）
- **D.** 承认"完成比完美更重要"，先发出去，根据反馈再迭代修改 → 🐢 渐进改革法

---

### 第17题：你发现自己在生活中经常做"后悔决定"——买完就降价、选完就想换，你会怎么改？

- **A.** 记录每次后悔的决定，找出规律：是不是总在情绪激动时做决定？ → 🪞 认知偏差识别法
- **B.** 建立一个"决策冷静期"规则：任何超过一定金额或影响的决定，必须等24小时再做 → 🧠 双系统思维
- **C.** 学会问自己："如果我不做任何决定，会发生什么？"——很多时候不行动就是最好的行动 → 📐 边际思维
- **D.** 接受"后悔是决策的一部分"，把重点从"避免后悔"转移到"提高决策质量" → 🧘 无为而治法

---

### 第18题：你要组织一场大型活动（年会/发布会/团建），预算有限但期望很高，你会？

- **A.** 先搞清楚这场活动的核心目标是什么——是庆祝？是营销？还是团队建设？只围绕核心目标花钱 → 🔍 矛盾分析法
- **B.** 找一个"让人印象深刻"的亮点（一个震撼的环节），其他环节尽量简化 → 🎯 战争重心法
- **C.** 把活动拆成几个阶段筹备：策划→预热→执行→复盘，每个阶段有明确的交付物 → ⏳ 持久战思维
- **D.** 发动参与者一起出主意——让大家贡献创意和资源，降低你的组织成本 → 👥 群众路线法

---

### 第19题：你读了一本很受欢迎的书/看了一部很火的剧，但你觉得一般般，你会？

- **A.** 好奇地想一想：为什么我觉得一般？是我的审美出了问题，还是这本书真的有缺陷？ → 🪞 认知偏差识别法（审视自身偏差）
- **B.** 去看看那些喜欢它的人是怎么评价的，找出它真正打动人的核心要素 → 👥 群众路线法（从受众中来）
- **C.** 不纠结这个感受，把它当成一次"框架效应"的观察：同样的内容，不同的人有不同的框架 → 🖼️ 框架效应法
- **D.** 直接放下，去找更符合自己口味的东西——时间宝贵，没必要在不喜欢的东西上消耗 → 🧘 无为而治法

---

### 第20题：你的人生中长期有一个"想做但一直没做"的事情（比如写一本书、开一家店、去一个地方旅行），你会？

- **A.** 现在就开始——不追求完美，先做一个最小版本，边做边调整 → 🐢 渐进改革法
- **B.** 分析一下：为什么一直没做？是害怕失败？还是资源不够？找到真正的阻碍 → 🔍 矛盾分析法
- **C.** 找一个正在做类似事情的人，跟他学、跟他合作，借力推进 → 🤝 统一战线法
- **D.** 先不着急——等一个合适的时机出现，顺其自然，不要强求 → ⏳ 持久战思维（战略耐心）

#### 🔴 如果你是"抓要害"型（A最多）

**你的超能力：一针见血**

你天生擅长在复杂局面中抓住核心矛盾。别人被表象迷惑时，你能一眼看到本质。你的思维方式像一把手术刀——精准、锋利、直击要害。

**典型表现：**

- 开会时总能说出"所以真正的问题是……"
- 面对一堆问题，你知道先解决哪个能带动全局
- 不喜欢绕弯子，习惯直奔主题

**潜在盲区：**

- ⚠️ 可能过于关注"主要矛盾"，忽略了次要矛盾的累积效应
- ⚠️ 有时会让他人觉得你"太直接"或"不够耐心"
- ⚠️ 在需要多方协调的场景中，可能低估了"人"的因素

**推荐加强：**

1. 🟡 **目标管理法 (#18)** — 学会把"抓到问题"转化为"可执行的拆解目标"
2. 🟢 **实事求是法 (#5)** — 在做判断前，多做一些实地调研和数据验证
3. 🔄 **反馈回路法 (#29)** — 关注问题之间的动态关系，不只是静态的主要矛盾

---

#### 🟡 如果你是"建体系"型（B最多）

**你的超能力：结构化思考**

你擅长把复杂问题拆解成可管理的模块，用系统化的方式分析和解决。你的思维像一张精密的地图——有条理、有层次、有路径。

**典型表现：**

- 做事习惯列计划、设里程碑、定KPI
- 面对新问题，会先找类比、找模型、找框架
- 不喜欢凭感觉做决定，总要有一些数据或逻辑支撑

**潜在盲区：**

- ⚠️ 可能陷入"分析瘫痪"——想得太细，行动太慢
- ⚠️ 有时忽略了"人"的非理性因素（情绪、直觉、文化）
- ⚠️ 过度依赖框架可能导致"拿着锤子看什么都是钉子"

**推荐加强：**

1. 🔴 **矛盾分析法 (#1)** — 学会在复杂体系中快速识别最关键的那个点
2. 🟢 **灵活策略法 (#11)** — 给计划留一些弹性空间，拥抱不确定性
3. 🧘 **无为而治法 (#21)** — 有时候"不干预"比"精心设计"效果更好

---

#### 🟢 如果你是"接地气"型（C最多）

**你的超能力：务实灵活**

你不喜欢空谈理论，习惯从实际情况出发，灵活应对变化。你的思维方式像一棵树——根深扎在土壤里，枝叶随风摆动但不会折断。

**典型表现：**

- 遇到问题先"去看看实际情况"，而不是坐在办公室里想
- 计划赶不上变化时，你能快速调整而不焦虑
- 善于从一线实践中汲取智慧

**潜在盲区：**

- ⚠️ 可能过于依赖经验，缺少前瞻性的战略思考
- ⚠️ 灵活有余但定力不足——容易随波逐流
- ⚠️ 在需要长期坚持的事情上，可能缺乏"持久战"的耐心

**推荐加强：**

1. 🔵 **战略预判法 (#7)** — 在灵活应变的同时，增加对未来的系统性预判
2. ⏳ **持久战思维 (#3)** — 学会在短期内看不到回报的事情上保持耐心
3. 🧩 **多元思维模型法 (#17)** — 把实践经验抽象成可复用的模型

---

#### 🔵 如果你是"重节奏"型（D最多）

**你的超能力：节奏大师**

你擅长把握事情的节奏和时机，不急不躁、步步为营。你的思维方式像一个优秀的指挥家——知道什么时候该快、什么时候该慢、什么时候该停顿。

**典型表现：**

- 做事有章法，不急功近利
- 善于分阶段推进，每个阶段都有明确的目标和检查点
- 在压力下仍能保持自己的节奏

**潜在盲区：**

- ⚠️ 可能过于追求"完美节奏"，错过了快速出手的机会
- ⚠️ 渐进式思维在面对需要"断崖式突破"的场景时可能不够用
- ⚠️ 有时会让同伴觉得你"太慢"或"太谨慎"

**推荐加强：**

1. 🔴 **矛盾分析法 (#1)** — 学会在关键时刻快速识别并集中力量突破
2. 🦎 **灵活策略法 (#11)** — 增加应对突发变化的敏捷度
3. 🌱 **自然选择法 (#23)** — 在必要时敢于"多试几个方向"，而不是只走一条路

## 📚 推荐学习路径

### 第一阶段：补足基础（1-2周）

根据你的主导倾向，选择对应的入门思维模式：

| 倾向 | 第一个要学的模式 | 学习要点 | 实践练习 |
|------|---------------|---------|---------|
| 🔴 | 反馈回路法(#29) | 理解正反馈和负反馈的区别 | 画一个你当前项目的因果回路图 |
| 🟡 | 矛盾分析法(#1) | 区分主要矛盾和次要矛盾 | 列出你手头3个问题，排序找"主要矛盾" |
| 🟢 | 战略预判法(#7) | 把握全局、预见趋势 | 对你关注的行业做一份3年趋势预判 |
| 🔵 | 灵活策略法(#11) | 保持开放、快速响应 | 为当前项目设计A/B/C三个应急方案 |

### 第二阶段：组合使用（2-4周）

将新学的模式和你的优势模式组合：

| 你的倾向 | 组合方式 | 练习场景 |
|---------|---------|---------|
| 🔴 | 抓要害 + 反馈回路 = **"系统狙击手"** | 找一个复杂问题，先用矛盾分析法定位核心，再用反馈回路法理解动态关系 |
| 🟡 | 建体系 + 矛盾分析 = **"精准架构师"** | 先搭建系统框架，再在其中找到最关键的那个矛盾点 |
| 🟢 | 接地气 + 战略预判 = **"远见实干家"** | 从一线实践中发现问题，然后用战略预判法推演未来趋势 |
| 🔵 | 重节奏 + 灵活策略 = **"敏捷指挥官"** | 在有节奏的推进中，保持对突发变化的灵活应对能力 |

### 第三阶段：融会贯通（长期）

当你的辅助思维模式足够丰富时，尝试"混搭"：

> 📖 参考文档：`thinking_mode_selector.md` 中的「思维模式混搭指南」
>
> **混搭三原则：**
>
> 1. 不同来源的组合 > 同一来源的组合
> 2. 功能互补 > 功能重叠
> 3. 2-4个思维模式混搭为宜，不超过5个

**高频混搭组合推荐：**

| 组合名称 | 思维模式 | 适用场景 |
|---------|---------|---------|
| 🔥 黄金三角 | 矛盾分析 + 渐进改革 + 反馈回路 | 几乎所有复杂问题 |
| 🛡️ 防守组合 | 实事求是 + 冗余备份 + 损失厌恶 | 风险管理 |
| ⚡ 进攻组合 | 运动歼灭 + 农村包围城市 + 灵活策略 | 市场竞争 |
| 🧠 决策组合 | 双系统思维 + 边际思维 + 认知偏差识别 | 重大决策 |
| 👥 团队组合 | 群众路线 + 目标管理 + 批评与自我批评 | 组织管理 |

## 💡 最后的话

**思维模式没有好坏之分，只有适合和不适合。**

你的主导思维模式是你最自然的思考方式——它是你的天赋，也是你的舒适区。但舒适区的边界，往往就是你成长的边界。

做这次体检不是为了给自己贴标签，而是为了：

1. **认识自己** — 你习惯用什么方式思考
2. **看见盲区** — 你很少用到的思维方式
3. **主动选择** — 在需要的时候，有意识地切换到不同的思维模式

> 🎯 **记住：最好的思考者不是只有一种思维模式的人，而是能在不同场景下灵活切换多种思维模式的人。**
