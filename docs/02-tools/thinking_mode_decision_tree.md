> 覆盖 **20 种常见场景**，适用于战略决策、创新突破、团队管理、危机应对等。
>

>
> ⏱️ 用时：2 分钟 | 📄 适合打印或截图

## 使用方法

1. 依次回答 4 个问题（每个选一个答案）

3. 在下方找到对应的场景，查看推荐组合
4. 按操作步骤执行

### 1. 复杂战略决策 `A-1-X-P`

**典型场景**：公司要不要转型？个人要不要换赛道？城市要不要建地铁？

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 矛盾分析法 | #1 | 找到核心矛盾，抓住关键 |
| 战略预判法 | #7 | 把握全局，预见趋势 |
| 系统思维法 | #12 | 避免片面，统筹兼顾 |

**推荐理由**：战略决策最怕"头痛医头"。矛盾分析法帮你找到真正的问题所在（主要矛盾），战略预判法确保你不只看眼前（预见趋势），系统思维法防止顾此失彼（统筹全局）。

**操作步骤**：

```
第1步：列出所有问题（矛盾分析法）
  → 写下你面临的所有问题和冲突，不要筛选

第2步：区分主次（矛盾分析法）
  → 哪个问题"牵一发而动全身"？
  → 哪个问题解决后，其他问题会自动缓解？

第3步：画全局图（系统思维法）
  → 把主要矛盾和相关因素画成关系图
  → 标注正反馈（放大）和负反馈（抑制）

第4步：推演未来（战略预判法）
  → 如果选A方案，1/3/5年后会怎样？
  → 如果选B方案，1/3/5年后会怎样？

第5步：做决定
  → 选择主要矛盾最清晰、全局影响最可控的方案
```

**预期效果**：决策依据从"感觉"变为"分析"；能看到3-5年后的局面；知道什么是关键。

### 2. 创新突破 `B-1-Y/S`

**典型场景**：产品没有新意、技术遇到瓶颈、创意枯竭。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 灵活策略法 | #11 | 不拘泥旧模式，快速响应 |
| 渐进改革法 | #8 | 小步快跑，迭代完善 |
| 自然选择法 | #23 | 适者生存，多试多错 |

**推荐理由**：创新不是灵光一闪，而是大量尝试中的筛选过程。灵活策略法让你不固守旧思路，渐进改革法保证每次尝试都有收获，自然选择法告诉你：多试几个方向，活下来的才是对的。

**操作步骤**：

```
第1步：头脑风暴（灵活策略法）
  → 列出10个可能的方向，不管多荒谬

第2步：最小可行性测试（渐进改革法）
  → 选出最有希望的3个方向，各做一个MVP
  → 预算控制在总资源的10%以内

第3步：收集反馈（自然选择法）
  → 让真实用户试用，数据说话

第4步：淘汰与聚焦（自然选择法）
  → 保留1个表现最好的方向，砍掉其余

第5步：快速迭代（渐进改革法）
  → 每周一个小版本更新，持续优化
```

**预期效果**：不再纠结"哪个想法最好"，用数据说话；创新速度提升3-5倍；失败成本大幅降低。

### 3. 团队建设 `C-1-Y/P`

**典型场景**：团队效率低、士气差、成员之间矛盾多。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 群众路线法 | #2 | 从一线获取真实信息 |
| 批评与自我批评法 | #10 | 持续反思和改进 |
| 统一战线法 | #6 | 团结所有人，孤立问题 |

**推荐理由**：团队问题往往不是"谁不行"，而是信息不通、反馈不畅、缺乏共识。群众路线法确保你听到真话，批评与自我批评法建立持续改进的文化，统一战线法把所有人的目标对齐。

**操作步骤**：

```
第1步：一对一深谈（群众路线法）
  → 和每个成员单独聊30分钟
  → 问："你最近最大的阻碍是什么？""如果你是我，会最先改什么？"

第2步：汇总共性（群众路线法）
  → 找出出现频率最高的3-5个问题

第3步：坦诚复盘会（批评与自我批评法）
  → 你先自我批评（暴露自己的问题）
  → 然后每个人轮流说"我做得不好的地方"

第4步：建立同盟（统一战线法）
  → 明确团队共同目标
  → 把注意力引向外部挑战

第5步：持续改进机制（批评与自我批评法）
  → 每周站会 + 每月复盘 + 季度评估
```

**预期效果**：两周内摸清团队真实问题；一个月内建立坦诚文化；三个月内效率明显提升。

### 4. 长期竞争 `A-1-X/R`

**典型场景**：创业公司面对巨头、个人在行业里打拼。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 持久战思维 | #3 | 分阶段推进，不急于求成 |
| 农村包围城市思维 | #4 | 从边缘切入，逐步包围 |
| 渐进改革法 | #8 | 小步快跑，持续迭代 |

**推荐理由**：长期竞争的核心是"活下去并且越活越强"。持久战思维帮你规划三个阶段（防御→相持→反攻），农村包围城市思维帮你找到巨头看不上的细分市场，渐进改革法确保你在每个阶段都在进步。

**操作步骤**：

```
第1步：评估实力对比（持久战思维）
  → 诚实评估你和对手的资源差距
  → 差距>5倍：进入防御阶段

第2步：找到薄弱市场（农村包围城市）
  → 对手在哪些细分市场上服务不好？
  → 选择一个对手"看不上"的市场

第3步：建立根据地（农村包围城市）
  → 在这个细分市场做到第一
  → 积累口碑、资金、人才

第4步：逐步扩展（农村包围城市）
  → 从根据地辐射到相邻市场
  → 每次扩张不超过现有规模的50%

第5步：等待时机（持久战思维）
  → 规模达到对手30%-50%时进入相持阶段
  → 继续深耕优势领域
```

**预期效果**：1年内站稳脚跟；2-3年在细分市场建立优势；5年后具备与巨头正面竞争的能力。

### 5. 危机应对 `D-2-Z/P`

**典型场景**：公关危机、资金链断裂、核心员工离职、产品重大故障。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 实事求是法 | #5 | 直面真相，不被情绪左右 |
| 灵活策略法 | #11 | 快速调整，不拘泥计划 |
| 矛盾分析法 | #1 | 找到危机的核心 |

**推荐理由**：危机中最危险的不是问题本身，而是信息失真和反应迟缓。实事求是法确保你看到真相，矛盾分析法帮你快速定位核心问题，灵活策略法让你在情况变化时迅速调整。

**操作步骤**：

```
第1步：止血（实事求是法）
  → 停止所有非必要的支出和行动
  → 召集核心成员，要求只说事实，不谈猜测

第2步：定位核心问题（矛盾分析法）
  → 列出所有问题，按严重程度排序
  → 找到"如果不解决，其他都会跟着完蛋"的那个

第3步：制定应急方案（灵活策略法）
  → 设计3个方案：保守/激进/折中
  → 选择一个立即执行

第4步：执行+监控（实事求是法）
  → 每天检查进展
  → 方案无效立即切换，不要为了面子死撑

第5步：事后复盘（实事求是法+矛盾分析法）
  → 写完整的复盘报告
  → 建立预防机制
```

**预期效果**：24小时内控制局面；7天内找到核心问题并启动解决；危机后建立预防机制。

### 6. 商业竞争 `A-1-Y/P`

**典型场景**：新产品上线面对竞品、争夺市场份额、价格战。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 全胜思维 | #13 | 不战而胜，最小代价 |
| 多元思维模型法 | #17 | 多学科视角分析 |
| 运动歼灭法 | #15 | 集中优势，各个击破 |

**推荐理由**：商业竞争不是"谁更狠"，而是"谁更聪明"。全胜思维提醒你不要正面硬拼，多元思维模型法帮你从多个角度理解竞争格局，运动歼灭法告诉你集中力量打你能赢的仗。

**操作步骤**：

```
第1步：知己知彼（全胜思维）
  → 列出自己和对手的优势、劣势、资源
  → 找出对方"必须赢但你不需要赢"的战场

第2步：多角度分析（多元思维模型法）
  → 经济学视角：供需、边际成本、网络效应
  → 心理学视角：用户决策偏差、锚定效应
  → 军事视角：重心、补给线、制高点

第3步：找到你的生态位（全胜思维）
  → 对手在哪个细分市场上做得最差？
  → 你能不能在那里做到最好？

第4步：集中攻击（运动歼灭法）
  → 在你选定的生态位上，集中所有资源
  → 做到该市场的绝对第一

第5步：建立壁垒
  → 用品牌、网络效应、转换成本建立护城河
```

**预期效果**：避开正面价格战；在细分市场建立绝对优势；用差异化赢得竞争。

### 7. 投资决策 `A-2-X/P`

**典型场景**：是否投资某个项目？资产配置如何调整？

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 边际思维 | #19 | 增量分析，关注边际变化 |
| 损失厌恶思维 | #26 | 理解人对损失的敏感度 |
| 双系统思维 | #27 | 区分直觉和理性 |

**推荐理由**：投资最大的敌人是自己。边际思维帮你理性分配资源（看最后一万元的回报），损失厌恶思维帮你识别自己的情绪陷阱，双系统思维确保你在重要决策时启动理性分析。

**操作步骤**：

```
第1步：边际分析（边际思维）
  → 不看总回报，看边际回报
  → 最后一万元投在哪里回报率最高？

第2步：识别情绪陷阱（损失厌恶思维）
  → 你是否因为"已经亏了"而不愿止损？
  → 你是否因为"怕错过"而过热追高？

第3步：强制冷静期（双系统思维）
  → 任何超过阈值的大额投资，强制等待24小时
  → 填写决策理由表，同时写"看空理由"

第4步：分散+聚焦
  → 核心仓位（60%）投在最确定的方向
  → 卫星仓位（40%）投在高潜力方向
```

**预期效果**：减少冲动交易70%以上；年化收益波动率降低；决策质量从"感觉"提升到"分析"。

### 8. 产品开发 `B-1-Y/S`

**典型场景**：从零到一打造一款产品。

| 思维模式 | 编号 | 作用 |
|---------|------|------|
| 群众路线法 | #2 | 从用户那里获取真实需求 |
| 渐进改革法 | #8 | 小步快跑，持续迭代 |
| 反馈回路法 | #29 | 理解增长的正负反馈 |

**推荐理由**：产品不是闭门造车做出来的。群众路线法确保你做用户真正需要的功能，渐进改革法让你快速试错，反馈回路法帮你建立增长飞轮。

**操作步骤**：

```
第1步：深入用户（群众路线法）
  → 连续三天跟随客服团队，记录用户抱怨
  → 发放问卷 + 深度访谈

第2步：确定核心需求
  → 找出提及率最高的3个需求
  → 排除"伪需求"

第3步：MVP开发（渐进改革法）
  → 2周内做出最小可行版本
  → 预算控制在总预算的10%

第4步：上线+收集数据（反馈回路法）
  → 识别正反馈（用户越多→内容越多→用户更多）
  → 识别负反馈（用户越多→内容噪音↑→优质用户流失）

第5步：持续迭代
  → 每周一个小版本

├─ B. 突破性问题（卡住了）
│   ├─ 资源充足 + 一般 + 要快 → B-1-Y/S 创新突破
│   ├─ 资源有限 + 一般 + 要快 → B-2-Y/S 技术攻坚
│   └─ 资源充足 + 紧急 + 要快 → B-1-Z/S 产品快速迭代
│
├─ C. 人相关问题（团队/人际）
│   ├─ 资源充足 + 一般 + 要赢 → C-1-Y/P 团队建设
│   ├─ 资源有限 + 一般 + 要赢 → C-2-Y/P 领导力提升
│   ├─ 资源匮乏 + 紧急 + 要赢 → C-2-Z/P 冲突调解
│   └─ 资源匮乏 + 一般 + 要快 → C-3-Y/S 人际关系
│
└─ D. 长期性问题（不是一两天能解决的）
    ├─ 资源充足 + 一般 + 要长 → D-1-Y/R 个人成长规划
    ├─ 资源有限 + 一般 + 要长 → D-2-Y/R 组织能力建设
    ├─ 资源有限 + 紧急 + 要赢 → D-2-Z/P 危机应对
    └─ 资源匮乏 + 紧急 + 要赢 → D-3-Z/P 生死存亡
```
