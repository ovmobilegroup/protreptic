## 一、对比维度定义

| 维度 | 说明 | 评分刻度（1-5） | 1 = | 5 = |
|------|------|----------------|-----|-----|
| **抽象程度** | 思维模式从具体操作到哲学思辨的距离 | 1=具体操作 | 5=哲学思辨 |
| **复杂度** | 理解和应用的难度（需要多少前置知识/步骤） | 1=简单易用 | 5=高度复杂 |
| **适用场景** | 模式适用的组织层级 | 1=个人决策 | 5=宏观战略/文明级 |
| **时间跨度** | 模式关注的时序长度 | 1=即时/短期(<1天) | 5=长期(>1年) |
| **确定性** | 模式适用的环境可预测程度 | 1=高度确定 | 5=高度不确定 |

### 五维雷达图释义

```
        抽象程度
          │
    复杂度│          适用场景
          │
          │
    ──────┼─────
          │
    时间跨度│        确定性
          │
```

每个思维模式用5维向量 `(抽象程度, 复杂度, 适用场景, 时间跨度, 确定性)` 表示，便于量化比较。

## 四、互补模式对（功能互补/协同增效）

> **定义**：两个模式在功能上互为补充，组合使用产生"1+1>2"的效果。参考错题本中的冲突型错误和混搭指南。

### 黄金互补组（错题本已有验证）

| 模式对 | 互补机制 | 协同效果 |
|--------|---------|---------|
| **#1 矛盾分析法 + #8 渐进改革法** | 矛盾分析找"做什么"，渐进改革定"怎么做" | 先定位主要矛盾，再小步迭代解决。避免"盲目改革"和"分析瘫痪"。 |
| **#1 矛盾分析法 + #12 系统思维法** | 系统思维看"全貌"，矛盾分析做"取舍" | 先系统思维理清全局关系，再用矛盾分析找出杠杆点。先宽后窄。 |
| **#2 群众路线法 + #10 批评与自我批评法** | 群众收集"外部声音"，批评做"内部消化" | 从一线获取真实问题，通过批评与自我批评形成改进方案。内外结合。 |
| **#3 持久战思维 + #4 农村包围城市思维** | 持久战定"时间节奏"，农村包围定"空间路径" | 持久战的三个阶段+农村包围的四步法=完整的长期竞争战略。时空结合。 |
| **#5 实事求是法 + #2 群众路线法** | 群众提供"一手资料"，实事做"验证分析" | 到一线去收集数据（群众），用科学方法验证（实事）。避免"拍脑袋"和"民粹"。 |
