## 一、每日应用日志模板

> ⏱️ **目标用时：3-5 分钟**
>
> 每次使用思维模式后，花 3 分钟填写以下字段。不必追求完美，关键是要养成记录习惯。

### 1.1 标准日志条目

```markdown
## 📝 {YYYY-MM-DD HH:MM} {简短标题}

- **场景**：{什么问题 / 什么任务 / 什么决策}
- **使用的思维模式**：{#编号 + 名称}（可多选，用逗号分隔）
- **过程记录**（≤3 句话）：
  1. {你做了什么分析 / 采取了什么步骤}
  2. {关键决策点是什么}
  3. {执行过程中有什么调整}
- **结果**：{成功 ✅ / 失败 ❌ / 部分成功 ⚠️}
- **效果评分**：⭐⭐⭐⭐⭐（1-5星）
- **反思**：
  - ✅ 做对了什么：{1句话}
  - ❌ 做错了什么：{1句话}
  - 💡 下次怎么改：{1句话}
```

### 1.2 填写示例

```markdown
## 📝 2026-07-11 14:30 项目优先级排序

- **场景**：团队同时面临服务器宕机、功能延期、核心员工离职三个问题，资源只够解决一个
- **使用的思维模式**：#1 矛盾分析法
- **过程记录**：
  1. 列出三个问题，画出因果链：服务器宕机→用户流失→收入下降→员工想离职
  2. 识别服务器稳定性是主要矛盾（根因）
  3. 集中全部运维资源修复服务器，功能延期暂缓
- **结果**：成功 ✅
- **效果评分**：⭐⭐⭐⭐⭐
- **反思**：
  - ✅ 做对了什么：画了因果链，避免了"同时抓三个问题"的老毛病
  - ❌ 做错了什么：没有提前和员工沟通暂缓计划，导致部分人心浮动
  - 💡 下次怎么改：矛盾分析后，加一步"影响范围评估"，提前沟通
```

### 1.3 快捷标签体系

为方便后续统计，可在每条日志末尾添加标签：

```
#场景:{工作/学习/生活/决策/管理/写作}
#模式:{矛盾分析/群众路线/持久战/实事求是/系统思维/...}
#结果:{成功/失败/部分成功}
```

示例：`#场景:工作 #模式:矛盾分析 #结果:成功`

## 五、快速使用指南

```
         → 回到本文件，花 3 分钟填写日志条目
         → 添加快捷标签
```
