## 1. 毛泽东 (1893-1976) · 近代 · 新民主主义革命总设计师 / 体系化纲领构建者

**独特思维贡献**  
将「主义×建党×建军×建国」四维工程化为可复用的革命完整工程体系：纲领先行定性质，建党解决领导核心，建军解决暴力夺权，建国解决治理巩固——形成「纲领→组织→暴力→治理」闭环，且每一环都有可操作的策略战术模块（如「农村包围城市」解决建军落地、「统一战线」解决建党扩容、「新民主主义纲领」解决建国定性）。

**可复用思维步骤 (4 步)**  
1. **纲领定性**：用「主要矛盾分析」(模式 1) 锁定历史阶段性质，提炼最小可行纲领（如新民主主义五大任务）  
2. **核心组织**：用「统一战线法」(模式 6) 构建「核心层+同盟层+中间层」三层组织架构，解决领导力合法性来源  
3. **暴力工程**：用「农村包围城市」(模式 4) +「运动歼灭法」(模式 15) 设计非对称暴力夺权路径，将战略防御/相持/反攻三阶段模块化  
4. **治理固化**：用「制度化制衡」(模式 34) +「总体性思维」(模式 22) 将革命红利转化为国家治理体系，建立「党政军民学、东西南北中党政军民学」全覆盖架构

**映射模式 ID 组合 (5 个)**  
`[42, 1, 6, 4, 34]` — 三民主义/体系化纲领 + 矛盾分析法 + 统一战线法 + 农村包围城市 + 制度化制衡

**优先级**: P0（填补模式 42 单点独占，补全「革命纲领工程化」空白）

## 2. 黄炎培 (1878-1965) · 近代 · 职业教育先驱 / "黄炎培周期"提出者 / 实业自主实践者

**独特思维贡献**  
创立「职业教育=国家自强」模型：以「手脑并用、工学结合」为抓手，在列强垄断工业技术、官僚资本排挤民族工业的双重夹击下，通过「办厂办学一体化」「师徒传承+现代课程」双轨制，实现技术自主、人才自主、资本自主的「三自」闭环。其「黄炎培周期」（治理周期律：其兴也勤俭，其亡也奢靡）更将历史循环律转化为可监测的组织健康度指标体系。

**可复用思维步骤 (5 步)**  
1. **卡脖子识别**：用「实事求是」(模式 5) 盘点核心技术/人才/供应链的外部依赖度，列出「必须自主」清单  
2. **最小可行闭环**：用「摸石头过河」(模式 38) 设计「办厂养校、校厂合一」最小闭环，用现金流验证自主可行性  
3. **双轨人才制**：用「知行合一」(模式 37) 建立「师徒传承(隐性知识)+现代课程(显性知识)」双轨培养，解决人才断层  
4. **资本边界管理**：用「鸟笼经济」(模式 39) 设定「民族资本不出鸟笼、外资不进核心层」边界，在鸟笼内最大化市场活力  
5. **周期健康度监测**：用「反馈回路」(模式 29) 将「勤俭→奢靡→亡」转化为可量化指标（研发投入占比、人才流失率、现金流安全垫），建立预警仪表盘

**映射模式 ID 组合 (5 个)**  
`[9, 38, 37, 39, 29]` — 独立自主法 + 摸石头过河 + 知行合一 + 鸟笼经济 + 反馈回路

**优先级**: P0（填补模式 9「独立自主法」零覆盖空白；模式 39 单点独占补强）

## 3. 薛暮桥 (1904-2005) · 当代 · 价格改革理论奠基人 / 市场社会主义经济学派创始人 / 风险决策实践者

**独特思维贡献**  
将「价格=信息+激励」的信息论视角引入计划经济改革：提出「价格双轨制」(计划价+市场价并存)、「价值规律是社会主义经济规律」，并首创用「损失厌恶」框架解释改革阻力——改革创造的收益是分散的、长期的，而损失是集中的、即时的，因此必须设计「补偿机制」与「渐进容错」来对冲损失厌恶。其「必要的损失vs不必要的损失」区分，成为改革风险决策的核心启发式。

**可复用思维步骤 (4 步)**  
1. **损失账单建模**：用「损失厌恶思维」(模式 26) 列出改革各利益相关方的「即时损失清单」（量化金额/权力/地位损失），识别「集中损失群体」  
2. **补偿机制设计**：用「边际思维」(模式 19) 设计「针对性补偿/过渡安置/利益分享」，使损失群体边际收益≥边际损失  
3. **双轨容错通道**：用「摸石头过河」(模式 38) 开辟「计划轨+市场轨」并行通道，允许市场轨在「鸟笼」(模式 39) 内试错，计划轨兜底  
4. **信息流速监测**：用「驿站制/信息流速」(模式 41) 建立「价格信号→企业决策→资源重配→反馈中央」高频反馈回路，将改革信号传递延迟压缩至月度级

**映射模式 ID 组合 (5 个)**  
`[26, 19, 38, 39, 41]` — 损失厌恶思维 + 边际思维 + 摸石头过河 + 鸟笼经济 + 驿站制/信息流速

**优先级**: P0（填补模式 26「损失厌恶思维」零覆盖空白；模式 39/41 单点独占补强）

**可复用思维步骤 (5 步)**

**映射模式 ID 组合 (5 个)**
