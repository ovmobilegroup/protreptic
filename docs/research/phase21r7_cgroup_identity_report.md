## 一、方法与口径

1. 证据分级（本报告每件分列）：
   - **确证**：权威来源（政府/官方媒体/权威出版物/百科引证）可直接支撑的事实；
   - **疑似**：检索快照或不完整史料支持、尚需逐字核原件的线索；
   - **查不到**：在下列检索范围内未见任何支撑，作为否定记录如实登记（否定结论不等于「不存在」的最终判定，仅代表本卡检索范围的负结果）。
2. 结论枚举（按卡面要求）：**已确证 / 无法核实 / 多候选细分**。本卡用法：载荷所载身份（姓名+时代+生平要点+作品）有权威来源支撑者=已确证；无任何支撑且无候选者=无法核实；找到可辨析的真实同名/近名候选（需船长细分辨别）者=多候选细分。**本卡 6 件待核件无一判「已确证」**（无一载荷身份能被支撑）。
3. 库内检索范围：活跃层（data/、tools/、docs/，排除 .git/site_docs/_duplicates/backup_）、归档件本体、git 全历史 git log -S（含已删除文件）、残件刮查（登记互引/机制键/遗留块）。
4. 公开检索范围：Web 检索（多后端，检索时点 2026-09-23），每件多轮查询（姓名 / 姓名+身份关键词 / 作品名 / 出处名组合）。局限：仅达公开可索引面；未访问付费数据库（知网、读秀等）；ctext.org 有反爬声明，仅采用其检索快照、未逐字核原书（对应条目已标注「疑似」）；搜索引擎快照可能不含完整书目信息。
