### 3.1 取证原则

- 事实来源与口径：一律取 git 对象（短号解析全号 / 日期 / 题名 / blob sha256）、文件字节（sha256）、工具实跑输出、DB 行读；不采信卡面或提交信息自述（QA 同口径）。

### 3.2 镜像与发布口径

- 镜像判定 = byte-exact（两仓 sha256 相等）；发布仓侧同时做提交级 blob 逐件对照（镜像提交对齐工作仓对应提交 P1->A / P2->B / P3->C）。
- 发布面复核 = (1) 两仓 byte-exact + (2) 提交级 blob 对照 + (3) push 面 ls-remote + (4) 线上站点抽验（时点值）。
- 执行链镜像事实：无（pb 零引用 e5ddd13f 且非其对象；QA-W9-F4 登记）。

### 3.3 生成口径（幂等）

- 本报告由 build_w9_fclass_archive.py 逐字段装配（生成时实测）；--check 复跑校验。
- 归一规则（--check 时替换后比对）：(1) 两仓 HEAD 观测行；(2) parity / ls-remote 观测行；(3) 本档件 sha 行；(4) 数据面现值列；(5) 线上抽验数值行。其余全文逐字节比对，打印 IDEMPOTENT 字样。
- 回执区（第四.7 节）为提交后回填区：v1 落盘时为占位，v2（回执终版）回填 v1 实测值，v2 及终态 sha 以卡面完成 metadata 为准（先例同体例）。
