## 6. 落地执行指引 (给 elcano)

### 6.1 批量写入脚本参数
```bash
# 生成 Phase 2 全量数据
python3 tools/data_merger.py \
  --phase 2 \
  --input-dir <repo>/tools/json/phase2/ \
  --output-dir <repo>/tools/ \
  --schema v6 \
  --validate
```

### 6.2 关键检查点
1. **双语一致性**：`reason_zh` / `reason_en` 语义对等
2. **模式编号有效性**：`modes` 数组引用的模式必须存在于 `modes_data.json`
3. **代码唯一性**：`code` 全局唯一，`code_maps.json` 双向映射正确
4. **Schema 校验**：23 字段完整，必填字段非空
5. **测试通过**：`python3 tools/test_thinking_mode_selector.py` 24/24 通过
