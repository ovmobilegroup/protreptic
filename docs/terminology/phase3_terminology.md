## 📋 术语表使用说明

### 核心原则

1. **中英文严格对齐**: 每个术语都有完整的中英文对照
2. **术语标准化**: 统一历史人物、思维模式、核心概念的翻译规范

- 历史人物姓名、官职、著作、事件

## 🔍 术语使用建议

### 术语选择原则

1. **准确性**: 选择最能准确表达原意的术语
2. **一致性**: 在同一文档中保持术语一致性
3. **专业性**: 使用专业术语，避免口语化表达
4. **可理解性**: 考虑目标读者的理解能力

### 术语使用规范

1. **首次出现**: 术语首次出现时提供完整的中英文对照
2. **重复使用**: 后续使用时可只使用中文或英文
3. **术语表**: 提供完整的术语表供参考
4. **更新维护**: 定期更新术语表，确保术语的准确性

### 术语翻译建议

1. **人名**: 使用标准拼音翻译
2. **地名**: 使用标准地名翻译
3. **官职**: 使用历史学界的标准翻译
4. **著作**: 使用学术界通用的翻译
5. **概念**: 使用哲学、社会科学的标准翻译
